# 地球模型形成机制动画实现方案

日期：2026年10月10日。状态：实现方案，尚未实施本次三维动画改造。现有第四步的球面气压与风线分步展示、右侧二维热力剖面已经实现；本方案进一步将温度响应、气柱调整和风向形成直接放到地球模型上。

## 1. 目标与范围

第四步以亚洲大陆与邻近海洋为主案例，用同一段三维动画连续展示：季节背景 → 海陆温度响应 → 气柱与空气调整 → 大陆气压中心 → 气压带区域变化 → 近地面风及季风。

点击“播放地球形成过程”后，在同一个地球场景完成推导。相机、空气运动、气压与风向共享一条时间轴。可暂停、逐节点讲课、回退和重播，也可播放完整连续过程。

右侧二维剖面改为默认收起的辅助入口“查看剖面解释”，用于核对同高度气压和受力关系。学生不展开它，也应能从地球动画辨认主要原因、过程与结果。

本次核心范围为第四步东亚冬夏机制。第五步的地球水汽与降雨动画作为后续扩展，共用本次的粒子、高度和时间轴能力；不把第五步整页迁移作为第四步首版的依赖。

真实性边界：浏览器端不适合在本项目中直接运行完整天气模式。首版应实现可解释、连续、受主要物理关系约束的低分辨率模型，并明确标注“方向、相互作用和先后关系接近形成机制；时间、强度和雨量不是实测预测”。如果未来需要研究级真实性，应把模式计算放在离线预计算流程，平台只播放结果并保留数据来源说明。

## 1.1 真实性要求：从“画箭头”改为“场驱动流动”

连续动画不应把每一条风线当成预先画好的路径。更合适的做法是先生成随时间变化的温度场、气压场和水平风场，再让空气示踪粒子根据所在位置的局地风速积分移动。画面中的流线由同一风场采样得到，因此气压中心变化、风向转折和粒子运动保持一致。

采用“物理约束的教学模型”，而不是完整天气预报模型。模型保留形成机制中的主要关系：海陆热容量差异 → 温度场变化 → 气柱质量和近地面气压变化 → 气压梯度力 → 地转偏向与摩擦 → 近地面风。时间、幅度和粒子数量仍为视觉夸张参数，必须在界面上标为教学示意。

不绘制一个封闭、对称、局地的“海陆风小环流”来代替季风。亚洲季风应表现为大范围背景风场中的区域异常：大陆热力异常改变压力场，风场在数千公里尺度上逐渐重组，粒子从海洋或大陆源区自然汇入目标区域。

## 2. 画面结构

### 主画面

- 地球占据释放右侧剖面后的主要空间，始终保留大陆与海岸轮廓。
- 近地面、大陆上空和海洋上空的对象按地理坐标定位，跟随地球旋转和相机观察。
- 亚洲大陆与邻近海洋分别有小型定位标记；讲解高空与近地面时出现短弧参考线及对应文字。
- 当前节点只突出必要对象；先前知识保留为低亮度背景，后续答案保持隐藏。
- 下方保留一条简洁进度条和当前因果短句，不用新的大浮层覆盖地球。

### 相机

初始从亚洲—西太平洋斜上方观察；气柱节点轻缓转至能同时看到地表与径向高度的斜侧视角；风向节点回到斜俯视，便于判断水平偏转。无需让大陆透明或切开地球。

自动运镜仅在首次连续播放或从头重播时使用。手动拖动、切换视角或开启锁定后停止后续自动运镜；“回到机制视角”可恢复。暂停同时冻结相机动画，避免教师讲解时画面继续移动。

## 3. 三维动画分镜

单季连续演示建议约30—35秒，时长仅表示演示节奏。各节点完成可以自动停顿，也可平滑连续推进。

| 节点 | 直接在地球上发生的变化 | 1月冬季 | 7月夏季 |
|---|---|---|---|
| ① 季节背景 | 理想气压带的短弧参考先发生季节移动；大陆、海洋仅显示定位，保持海陆变量尚未加入的条件 | 参考带偏南 | 参考带偏北 |
| ② 温度响应 | 大陆与海洋出现低透明度的局部温度提示和不同速度的变化条；温度采用独立图例，此时不显示完整气压色块 | 大陆较快转冷，海洋变化较缓 | 大陆较快转暖，海洋变化较缓 |
| ③ 气柱与空气调整 | 大陆上方出现少量点状气柱标记；高度变化、径向粒子和较高层横向流动依次发生 | 气柱收缩，空气沿径向向地表下沉；较高层空气向大陆补充 | 气柱膨胀，空气沿径向离开地表上升；较高层空气向外输送 |
| ④ 大陆气压中心 | 温度提示逐渐淡出，气柱质量增减示意出现；大陆H或L与局部等压线从弱到强，先不显示季风 | 大陆近地面冷高压形成 | 大陆近地面热低压形成 |
| ⑤ 气压带区域变化 | 连续带的参考叠加逐渐转为同一气压场的区域分布，周围动力背景恢复，突出“同一季节加入海陆”的改变 | 亚洲高压改变副极地低压带连续分布 | 亚洲低压改变副热带高压带连续分布 |
| ⑥ 风向与季风 | 先显示球面上的气压梯度推动方向；示踪气团开始运动，再展示右侧偏向与摩擦影响，逐渐形成最终近地面风向 | 气流由大陆流向海洋，形成东亚偏北冬季风 | 气流由海洋进入大陆，形成东亚偏南夏季风 |

最终归纳保留大陆H/L与主要季风，其余气柱、受力箭头和高空气流淡出，恢复清晰的冬夏气压与风向分布图。可重播，或切换另一季节形成过程。

## 4. 怎样把剖面中的对象变成球面对象

### 上升与下沉

上升沿当地地表法线向外，下沉沿法线向内，以地球球心为参考；不能使用屏幕固定的向上／向下方向。若转动地球，同一地区的上升仍然从该地区地表向外。

气流粒子到近地面即停止下降，不穿入地球。用短的流线和粒子同时表示方向，避免单纯闪烁造成难以判断的运动。

### 气柱收缩与膨胀

在大陆与海洋上方各放置一组稀疏点阵或轮廓线，作为比较标记。大陆标记随季节收缩或伸长，海洋标记变化较小；周围空气保持开放，不绘制实心封闭圆柱。

气柱高度和运动幅度为夸张示意，不对应真实大气层厚度。建议先按地球半径的约8%—15%设计视觉高度，再以画面复核调整；这是视觉参数，不能作为真实比例宣传。

标记固定比较区域，不随移动粒子漂走。气柱体积变化与空气质量变化使用不同表达：高度体现收缩／膨胀，粒子出入及“气柱质量增加／减少”短句体现空气调整。粒子数量仅为示意，不用于计算气压。

### 高空气流

沿较高半径的球面弧线运动，明显高于近地面风线；按纬度、经度和高度定义路径，采样后保持在预定高度层，不能直接用穿过地球内部的空间直线。

只显示讲解区域的一两条代表路径，说明热力调整方向。避免将真实亚洲季风画成简单的封闭海陆风小环流，也不要求海洋一定出现与大陆完全对称的垂直运动。

### 气压与风

气压中心固定在实际示意位置，气流经过时不带走H/L标签。等压线在球面上逐步显现；近地面风始终贴近球面，和高空运动用高度、线型及文字区分。

近地面推动方向与最终风向分别表达：白色虚线为推动方向，橙色为运动风向，青色为偏向，紫色为摩擦。受力图只跟踪少数代表气团，形成结果后收起辅助受力箭头。

## 4.1 连续动画的推荐算法

连续动画不应把每一条风线当成预先画好的路径。建议先生成随时间变化的温度场、气压场和水平风场，再让空气示踪粒子根据所在位置的局地风速积分移动。流线由同一风场采样得到，因此气压中心变化、风向转折和粒子运动保持一致。

采用“物理约束的教学模型”，而不是完整天气预报模型。模型保留主要关系：海陆热容量差异 → 温度场变化 → 气柱质量和近地面气压变化 → 气压梯度力 → 地转偏向与摩擦 → 近地面风。时间、幅度和粒子数量仍是视觉夸张参数，界面继续标为教学示意。

不绘制一个封闭、对称、局地的海陆风小环流来代替季风。亚洲季风应表现为大范围背景风场中的区域异常：大陆热力异常改变压力场，风场在大范围上逐渐重组，粒子从海洋或大陆源区自然汇入目标区域。

### 温度场

在经纬度网格上定义陆地遮罩 `L(lat, lon)` 和海洋遮罩 `1-L`。每个网格保存温度扰动 `T'`，由季节目标温度和不同响应时间共同决定：

`dT'/dt = (T_eq(season, lat) - T') / τ(surface)`

陆地使用较短的 `τ`，海洋使用较长的 `τ`。切换冬夏时，陆地温度先变化、海洋变化更慢，而不是瞬间替换两张颜色贴图。加入海岸附近的扩散平滑，避免大陆边缘出现生硬色块边界。

### 气压场

气压扰动由季节背景、陆地热力异常和海洋动力背景组成：

`p' = p_season(lat) + a_land · smooth(L · T') + p_ocean_dynamical`

陆地热力项先经过空间平滑，再逐步增加权重；海洋动力背景独立控制，不能全部由海洋温度直接推导。气压场同时驱动色块、等压线、H/L透明度和风场，避免各图层使用不同结果。

### 风场

在球面局部切平面上计算水平风：

`du/dt = -α∇p - f k×u - r u + β·u_background`

气压梯度提供初始推动，`f` 为随纬度变化的科氏参数，`r` 为近地面摩擦，`u_background` 表示三圈环流和信风等背景。高空层减小摩擦，近地面层增加摩擦；风场由背景风连续过渡到季风异常，不直接把最终路径写死。

首版不求解完整三维原始方程，可在低分辨率经纬网格上用小步长更新，限制速度与梯度，保证离线浏览器稳定。风场每帧更新，等压线与流线按较低频率重采样并平滑插值。

### 示踪粒子

粒子采用二阶或四阶 Runge–Kutta 在球面切平面上积分，位置每步投影回对应高度层的球面：

`x(t+Δt) = Advect(x(t), u(x,t), Δt)`

粒子从海洋、亚洲大陆和背景风带源区持续补充，达到边界后重新生成。粒子颜色表达来源或高度，透明度表达生命周期，不排列成等间隔箭头，不显示固定三角箭头。需要强调方向时，用随速度场弯曲的亮带或粒子尾迹。

### 流线与尾迹

在当前粒子后绘制短暂速度尾迹，尾迹长度与速度成比例并逐渐淡出。可选显示低透明度短流线段，但每次都从当前风场采样，不能复用冬夏预设折线。这样画面表现为空气被压力场连续组织和输送，而不是箭头沿轨道移动。

### 参数连续过渡

每个节点只改变模型参数目标值，不切换静态结果：温度响应时间、陆地异常权重、背景风权重和摩擦系数使用缓动；已有粒子继续沿新风场转向。暂停只停止模拟时钟，恢复后从原粒子位置和速度场继续；回退恢复对应阶段的场参数和粒子快照。

## 5. 气压动画必须表达分布变化

目前程序主要通过完整气压纹理的透明度变化展示理想与真实结果。本次应改为在同一教学气压场中逐步增强大陆异常、再引入周围区域配置，使等压线随场变化，而不只淡入一张最终结果图。

建议分开准备三部分：理想纬向背景、大陆热力异常、海洋等动力背景。阶段进度控制各部分的展示权重，温度阶段不直接出现最终气压中心；气压阶段先突出大陆，气压带阶段再呈现区域配置。

色块、等压线和H/L应来源于同一阶段的气压示意场，避免色块已变化而等压线仍是另一幅结果。中间场用于教学过渡，不声称为真实季风演变的时间积分结果。

动态等压线无需每帧重新计算：可预计算若干阶段采样，或降低提取频率并平滑显示。纹理、线段缓冲和粒子对象复用，避免在每帧大量创建对象。

## 6. 风向偏转的三维表达

在代表气团所在经纬度建立当地东、北和向外三个参考方向，先在局部切平面判断推动与偏转，再映射回球面。气团前进时更新当地参考方向，偏向始终相对运动方向判断。

- 气压梯度推动来自当前示意气压分布，不把预设曲线起点简单当作高压。
- 北半球右偏是相对于气团运动方向，不是屏幕右侧；相机旋转不改变物理含义。
- 摩擦箭头与当前速度反向；偏向箭头与当前水平速度垂直。
- 近地面终态风斜穿等压线向低压，不画成气压梯度力、偏向力分别把整条线一次转弯的机械过程。

首版可采用方向推导与轨迹逐段变形的示意动画。若以后加入简化动力积分，必须明确模型条件，不能将动画宣称为真实天气或定量季风模拟。

## 7. 保证大陆轮廓和因果层次清晰

温度层和气压层在同一位置按阶段接替，减少色义混淆。局部温度提示限定在大陆／海洋比较区，使用边缘强调与低透明度填色，不覆盖整个亚洲。

地表提示可利用低分辨率海陆遮罩或区域多边形限制范围；不能根据卫星贴图颜色直接猜测海陆。首版只制作亚洲案例需要的比较区域与轮廓，之后再扩展全球。

空气标记位于地表上方，密度保持较低；高空线和气柱不遮住大陆名称。正常深度遮挡背面对象，不把地球背面的粒子透视显示到正面。标签根据朝向和遮挡隐藏，优先保留当前地区、H/L和当前机制短句。

关闭粒子时仍保留必要方向箭头，关闭气压图层时同时隐藏相应色块、等压线和H/L。辅助示意的显隐规则保持一致，避免图层开关导致方向无法判断。

## 8. 冬夏对照与交互

新增主操作“播放地球形成过程”，默认连续播放，符合观看一段完整形成动画的需求。讲课模式可选择“每节点停顿”；已有上一节点、下一节点、当前解释、重播与速度调节继续复用。

冬夏完整对照可以在冬季形成结束后停留，再切换夏季，从温度响应重新推导。两季使用各自的气压背景与路径；不能只把冬季箭头反向便称为夏季机制。

回退时按阶段重新计算三维对象状态，收起后续H/L与风线。中途切季节、切区域或跳步骤时取消当前运镜与动画任务，避免旧粒子、旧字幕和旧视角继续推进。

非亚洲区域首版维持结果对照，不套用东亚机制。打开辅助剖面与主动画共享时间轴，避免各播各的；合上剖面后恢复地球取景空间。

## 10. 实施顺序

1. **冬季三维样例**：完成温度响应、径向下沉、高空补充、大陆高压与近地面风，先核对侧视和俯视方向。
2. **夏季及气压场过渡**：补上膨胀、上升、高空外流、热低压与海洋来风；将色块、等压线、标签统一到阶段气压场。
3. **完整动画与辅助剖面**：接入连续播放、运镜、字幕、停顿、回退和重播，剖面改为默认收起。
4. **清晰度与交付验证**：调整粒子数量、透明度、标签及高度，复核小屏、投屏、离线与原步骤回归。

每一步都形成可播放版本，优先保证运动方向和教学因果正确，再增加视觉细节。

## 11. 验收标准

### 教学画面

- 收起剖面，仅看地球即可辨认温差、上升／下沉、高空调整、气压中心和季风形成的先后。
- H/L与完整风线不在开始前出现；温度响应阶段不使用气压图例解释温度。
- 冬夏两种过程各自正确；海洋动力气压背景不被表现为单纯冷暖导致。
- 亚洲与邻近海洋轮廓在各阶段清楚，背面对象不穿透地球显示。
- 从斜侧视、俯视和手动旋转后的视角观察，径向上升／下沉和当地右偏仍然正确。

### 程序与交互

- 暂停冻结粒子、气压过渡、字幕进度和自动运镜；速度调节同步作用于同一时间轴。
- 回退、重播、季节切换、跳步骤后没有旧对象或旧相机任务残留。
- 用户拖动或锁定相机后，自动运镜不夺回控制；恢复机制视角入口正常。
- 气压色块、等压线、H/L与受力图在同阶段一致；所有路径均在地表之上，高空与近地面可区分。
- 验证桌面、小窗口与投屏画面，以及断网双击和现有前三步、第四步结果对照、第五步功能。
- 记录实际帧率和图形负载，性能不足时先减少粒子与等压线更新频率，不删除关键因果节点。

### 学生理解

观看后让学生独立解释：为什么先有海陆温差却不能直接跳到季风？近地面高低压与上方空气柱质量怎样联系？地球旋转后，为什么“向右偏”仍不等于屏幕向右？冬夏为什么需要分别推导？

程序完成与试教效果分别记录，不把视觉流畅等同于学生理解。

## 12. 第五步后续扩展

本次三维高度与粒子能力稳定后，可在同一地球上把海洋水汽、向岸输送、局部抬升与云雨串起来。孟买使用放大的迎风地形示意，达尔文按南半球季节切换；局部地形高度仍须标为夸张示意。

第五步的全球展开图与气候年变化图继续承担读图和归纳功能。三维云雨动画说明机制，预设月资料说明季节统计特征，两者不建立虚假的粒子数量到月雨量计算关系。

# 第四步问题检查：衔接前三步的教学逻辑与设计风格

检查日期：2026年10月21日。范围为当前工作区生成页面及源码，覆盖1月/7月、六个形成节点、形成机制/结果对照、亚洲/美洲切换，以及1366×768、760×800、390×844窗口。已实际运行浏览器并保存截图；未进行课堂试教。

## 判断基准

前三步已经建立了一条清楚的条件变化链：

1. **第一步**：均匀地表，忽略自转偏转，解释受热差异如何形成单圈。
2. **第二步**：加入自转的偏转作用，连续展示三圈形成。
3. **第三步**：保留均匀地表，展示三圈环流、气压带与风带及其季节移动。
4. **第四步应承接的任务**：在同一季节、同一地球背景上加入海陆差异，解释连续气压带为什么发生区域变化，并进一步形成季风。

设计上应延续：地球作为主画面、条件逐项加入、气流过程可追踪、名称与箭头对应、辅助内容按需展开、播放与暂停规则清楚。

## 建议的第四步教学顺序

1. **承接第三步**：保留当前季节的理想三圈、气压带与风带，标出“当前仍为均匀地表”。
2. **加入海陆差异**：同一地球上逐渐显现大陆与海洋，季节保持不变，说明新条件。
3. **比较海陆温度响应**：突出亚洲大陆与邻近海洋，展示陆地变化较快、海洋变化较慢。
4. **展示空气调整**：选取局部气柱，展示垂直运动、高空补充/外流和气柱质量变化；辅助剖面按需展开。
5. **形成区域气压中心**：冬季大陆冷高压、夏季大陆热低压逐渐显现，H/L与色块同步。
6. **对照原来的气压带**：冬季重点对照副极地低压带，夏季重点对照副热带高压带；海洋中心保留动力背景的说明。
7. **形成季风并比较冬夏**：先表示气压梯度的推动，再展示偏向及摩擦影响后的近地面风向；完成后可来回切换冬夏，固定同一观察区域。

此顺序保留现有六节点的主要内容，重点是把新增条件及因果联系搬到地球主画面上，并统一辅助图、标签和播放状态。

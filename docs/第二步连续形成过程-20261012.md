# 第二步连续形成过程

第二步的形成环节1—4共用40秒时间轴和同一组球面发光气流。各环节自动衔接，保留此前形成的轨迹；不会重置画面或自动进入第三步。

| 时间（1倍速） | 观察内容 |
|---|---|
| 0—4秒 | 赤道受热上升 |
| 4—12秒 | 高空气流向北运动并逐渐右偏，30°附近趋于沿纬线向东运动 |
| 12—19秒 | 高空汇入、积聚、下沉，近地面副热带高压带出现 |
| 19—23秒 | 近地面分流，连接哈德莱环流 |
| 23—33秒 | 60°附近冷暖气流辐合、较暖空气被抬升，归纳极地环流 |
| 33—40秒 | 连接间接的费雷尔环流，归纳三圈 |

点击“暂停并解释”或教师端暂停，可冻结全部气流并打开当前时刻的解释。选择“保持暂停”仅关闭解释；选择“继续播放”从暂停位置继续。拖动时间轴可回看任意位置，点击1—4或上一/下一形成环节可定位；“从头重播”重播整个过程。所有流动由同一时钟驱动，暂停时粒子位置保持不变。

北半球高空轨迹使用球面参数曲线：纬度为 `30(2t−t²)`，东经增量为 `48t²`，因此接近末端时南北运动分量趋于零，末端切线沿30°纬线向东。青色偏向箭头使用水平速度与当地径向的叉积，方向在运动右侧且与速度垂直。赤道、30°纬线及无偏转经线用于比较方向。

纬度、高度、光带宽度和时间均为教材机制示意，不代表数值模拟。解释明确区分水平偏转与大尺度积聚下沉；地转偏向力不直接向下推空气。南半球同步表示向南运动的左偏。光带表示平均环流联系，不表示气团沿固定管道循环。

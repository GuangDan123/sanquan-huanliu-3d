# 第一步单圈风格统一

第一步单圈环流参照第二步统一视觉设计：柔和、边缘渐隐的光带，半径0.025的细色芯，颜色匹配的粒子与移动箭头，以及外侧透明边缘大气层。赤道暖色橙黄，向极地依次过渡为黄绿、蓝绿、蓝色；颜色与第二步一致，为教学示意。

每个半球一条独立闭合路线，赤道附近上升、高空向极地输送、极地下沉、近地面返回赤道。路径经度不变，不加入地转偏向；球面圆弧连接上下层与升降段，接点位置及切向连续。高空高度1.45，大气层半径7.05，地表半径5；高度不按实际比例。形成过程仍忽略自转对气流的偏转，完成后的地表缓慢转动用于持续观察，太阳及受热不均说明保留。

第一步采用连续播放，点击播放后完成10秒形成过程，中间的四个阶段不自动暂停。动画开头按因果顺序展开：0—0.75秒先让阳光抵达大气层，0.75—1.45秒让赤道附近大气逐渐受热并由蓝色转为橙黄色，1.45秒后才开始地表空气上升及其气团、向上光柱箭头和赤道低压环波；受热上升段延长至3.4秒，以慢镜头清楚展示空气从地表上升到高空，并在路径旁标注“受热上升”，上升期间镜头推近。完成后保留完整环流，进度固定10秒；箭头、粒子、光带、光柱箭头和环波继续循环，地表缓慢转动。“暂停流动”冻结所有运动，“继续流动”从冻结位置恢复，“从头重播”重新演示形成过程。已移除分步停顿的播放方式和上一节点、下一节点、重播本节点按钮；保留阶段定位及进度回看。形成路线按时间逐渐展开，拖动进度条可回看；点击当前阶段的“显示本节点结论”可直接显示该阶段路线。形成完成后的运动时钟单独累计，回看、阶段定位和重播均清零，形成过程中的暂停与回看仍准确复现。

操作区统一为渐变色标、四个节点按钮、进度条与时间；提供“暂停并解释”，也可点击路径位置标记查看对应形成原因。解释窗口打开时允许拖动、缩放，气流保持暂停。手机解释窗口位于下方，太阳标签在手机上收起，避免顶部操作遮挡。

“轨迹”控制光带、色芯、光柱及箭头，“粒子”控制粒子与气团，“气压带”控制色带、气压提示和底部环波，“标注”控制过程标记及气压名称。默认开启气压效果，但播放前保持隐藏；赤道低压黄色带与两极高压紫色带随上升、下沉渐显，底部环波在赤道向内收缩、在两极向外扩散，形成后的提示持续保留。拖动时固定环流的空间方向，复位恢复默认全景且保留当前形成进度。切到第二、第三步时显式隐藏第一步模型、标签与解释，并恢复对应大气层。

赤道上升采用与第二步相同的九个柔和气团、发光粒子和两条向上光柱，气团随上升到达高空。受热上升从1.45秒开始，延长到3.4秒完成；“受热上升”标签贴在两条上升路径旁，镜头在1.45—3.4秒平滑推近，随后约1.7秒返回原全景。镜头与气流共用进度，暂停时完全静止，回看相同时间可复现相同画面；拖动接管镜头，视角锁定与关闭自动聚焦均受尊重。复位关闭当前自动特写，重播重新启用。太阳射线的两侧角度从8°缩小到4°，间距约减半。

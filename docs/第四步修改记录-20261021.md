# 第四步：在地球上演示形成过程

本次按课堂需求将右侧推导板撤出主画面，形成机制由同一个三维地球上的动画承担；适当节点保留简短标签。以下说明取代此前以右侧图解为主的版本。

## 地球上的七个阶段

1. 承接第三步当前季节，在均匀地表上逐渐显现海陆。
2. 陆地与同纬度海洋逐渐呈现冷暖差异，两根贴在地表的空气柱随温度收缩或膨胀。蓝、橙始终表示冷暖。
3. 在同一高空高度显示相对H/L，气流由高压侧向低压侧输送；大陆空气柱冬季下沉并增加粒子、夏季上升并减少粒子。粒子数量表示局部气柱质量关系，不是空气分子的实际数量或严格定量收支。
4. 大陆近地面气压中心及环线逐渐展开，H/L与冷热颜色分开表达。局部35°N气柱是热力关系示意；局部海陆中心位于103°E和153°E，冬季同为45°N、夏季同为30°N，便于比较邻近海陆。大尺度中心的地理位置在第七阶段呈现。
5. 对应理想气压带在大陆经度段逐渐收窄至中断，海洋段保留，并出现海洋气压中心；原带位置用虚线保留。海洋中心仍包含大尺度动力背景，并非仅由海陆温差生成。
6. 先显示白色虚线气压差推动方向，再让同一起点的橙色实线风向逐渐向右转。使用一条连续流线与单个箭头尖，减少串珠和碎箭头；配套图例区分推动方向与实际风向。冬夏分别归纳东亚偏北风、偏南风。路径、角度、高度、时长均为教学示意，不是天气轨迹。
7. 用7秒将局部示意归纳到完整气压、等压线与季风分布。局部中心和主风线平滑接入大尺度位置，参考带与局部标签退出，全球图层和结果标签逐渐显现；界面注明位置过渡用于归纳，不表示真实迁移。终态直接使用“结果对照”的同一套图层，切换时保持地球、相机与标注一致。

标签只在相应阶段出现，包括“降温较快”“高空补充”“气柱质量增加”“向右偏”等；退出形成模式后清除，避免与结果标签重叠。

## 课堂操作

- 左侧保留月份、阶段回看、播放/暂停、从头重播和结果对照。
- 连续播放共43秒（1倍速）；设置中可选逐段讲解，每阶段末暂停。
- 回看选择任一阶段，停在该阶段起点；点击播放验证。
- 冬夏切换保留当前阶段及进度并暂停，便于同一过程对照。
- 可以拖动、缩放地球观察局部竖直方向；暂停同步冻结流动、气柱形状、质量变化和风向。
- “海陆温度响应”开始时，镜头用约1.3秒自动转到北半球侧向视角，让两根气柱出现在地球边缘，清楚呈现柱高和升降气流；“空气柱与高空输送”保持此视角。“大陆气压中心”开始后的约1.2秒平滑恢复进入前的区域视角。镜头进度跟随动画，暂停不会继续转动。
- 中途查看结果或退出第四步会清理自动镜头并恢复正常视角；手动拖动或缩放可接管观察，视角锁定时不自动转动。侧向观察时，海陆短标签移到对应气柱外端，避免被地球遮住。
- 海陆短标签的文字框放在气柱外端之外并保留间距，避免压住端环、粒子与箭头；旋转观察时根据气柱的屏幕方向选择文字框靠左或靠右，返回常规视角后恢复居中锚点。已检查冬夏冷热及输送阶段在1600、1366像素宽度下均不与气柱相交。
- 连续播放自动到达完整分布，无需再点击结果按钮。结果模式保留原气压场、等压线与区域季风路径，以及简洁气压图例；各条季风路线使用连续箭头。
- 气压色区改为柔和渐变，局部环线降低亮度；新旧标签分时淡出、淡入。等压线数字避让使用实际标签尺寸，消除被隐藏后尺寸变为零引起的闪动。

## 检查

`tools/verify-landsea-globe.mjs` 检查冬夏形成阶段、气柱冷热响应及粒子增减、高空流线半径、气压中心渐显、大陆气压带中断与海洋保留、同起点右偏、阶段回看、同阶段冬夏切换、两种播放模式、暂停与退出，以及1920/1366/1100/760/390像素画面。

`tools/verify-landsea-overview.mjs` 专项检查冬夏归纳阶段、分布图层连续渐显、暂停、连续播放自动进入终态、终态切换结果图的画面像素一致、返回与回看，以及1366/760/390像素截图。

`tools/verify-landsea-camera.mjs` 检查冬夏镜头平滑进入、两柱侧向投影、暂停、连续播放自动切换及原位置/朝向/观察中心恢复，并检查手动接管、视角锁定、结果切换和退出清理；截图与报告位于 `output/landsea-camera/`。

截图与检查报告位于本地 `output/landsea-globe/` 和 `output/landsea-overview/`。此前 `verify-landsea-story.mjs` 和 `verify-landsea-continuity.mjs` 包含旧右侧面板的断言，不适用于本次界面。

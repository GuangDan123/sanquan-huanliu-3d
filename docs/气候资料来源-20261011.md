# 气候月资料来源

获取日期：2026年10月11日。来源：日本气象厅东京气候中心（JMA/TCC）ClimatView。

采用来源表格的Normal列：月平均气温（°C）与月降水量（mm），没有用2025年的Observation列代替气候常值。ClimatView的[资料说明](https://ds.data.jma.go.jp/tcc/tcc/products/climate/climatview/outline.html)明确其常值统计期为1991—2020年，来源包括CLIMAT报文及NOAA/NCEI的GHCN资料。

原表链接格式为 `https://ds.data.jma.go.jp/tcc/tcc/products/climate/climatview/graph_mkhtml.php?n=站号&y=2025&m=12`。月份参数用于展开全年的表格，平台提取的是常值列，统计期仍为1991—2020年。原始页面及说明存于开发项目的 `artifacts/teacher-review-20261011/sources/`；`src/climate-normals.js`保存提取后的12个月值，随成品内嵌。更新工具在数据缺失时停止，不以0补齐缺测。

数值核对示例：上海1月67.5 mm；孟买7月790.5 mm、11月8.8 mm；金奈7月104.3 mm、11月381.1 mm；达尔文1月468.0 mm、7月0.0 mm。0.0是来源的显示精度，不能理解为每年该月完全无雨。

真实常值仅用于读图与材料解释，地图气压、季风路线、粒子、气柱格数仍为教学示意。不能由动画单独计算这些气候统计值。孟买与金奈材料说明东北季风可从孟加拉湾获得水汽，也保留热带天气系统等因素，避免把全部降水归因于单一季风。

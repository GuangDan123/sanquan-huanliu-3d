# 第四、第五步形成机制完善方案

方案日期：2026年10月9日。2026年10月10日已按本方案实现平台形成机制与分步交互，验证记录见《形成机制实施与验证-20261010》。真实课堂理解效果仍需教师试教验收。

## 一、完善目标与五步定位

现有第四、第五步能够展示冬夏气压、风向和典型气候结果，但主界面的动态内容主要是箭头沿既定路线移动。完善后，应让学生能够按顺序观察原因、过程和结果，并在答案出现前作出预测。

| 步骤 | 核心问题 | 教学职责 |
|---|---|---|
| 第一步：理想单圈环流 | 纬度间受热差异如何驱动环流？ | 建立热力环流基础 |
| 第二步：地转偏向力介入 | 自转怎样改变气流方向与环流结构？ | 推导偏转、积聚、下沉、分流与抬升 |
| 第三步：理想三圈环流 | 理想地表上形成怎样的气压带和风带？ | 汇总前两步，提供后续比较基准 |
| 第四步：海陆分布与季风 | 季节性海陆受热差异怎样改变气压与风？ | 展示海陆温差、气压中心与季节风向的形成 |
| 第五步：季风环流与气候 | 季风怎样影响水汽、降雨和气候年变化？ | 展示水汽输送、抬升降雨与区域气候联系，并完成南亚与南半球迁移 |

第四步以东亚冬夏为主要机制案例；第五步以区域气候响应为主，南亚跨赤道季风作为特殊路径单独推导。两步共享季节、区域与风向信息，避免重复播放相同解释。

## 二、进入第四步前的衔接

从第三步进入第四步时，先显示简短条件卡：

- 保留地球自转与已有三圈环流背景。
- 引入季节变化，气压带随季节移动。
- 将均匀地表改为真实海陆，比较相同季节下的差异。

先用简短动画标出气压带季节移动，再进入海陆影响。已有“季节移动”课堂模块保留为详细探究入口。季节移动与海陆差异分开演示，避免学生无法判断哪个条件造成了改变。

## 三、第四步：海陆差异到季风形成

### 1. 画面组织

保留三维地球作为全球定位和最终分布图；增加可展开的“海陆热力剖面”，用局部二维图表达地表、近地面、高空及垂直运动。

主画面与剖面同步推进：温度差在剖面中解释，气压中心与气压带变化在地球上定位。默认聚焦亚洲与邻近海洋；美洲、太平洋视角继续用于结果对照。

剖面在宽屏显示于地球旁，小屏转为下方区域。不得覆盖正在讲解的大陆轮廓与关键H/L；机制开始时淡化无关风线和气压填色，结束后恢复完整分布。

### 2. 分阶段演示

| 节点 | 画面逐步出现什么 | 预测问题与应建立的认识 |
|---|---|---|
| ① 海陆受热差异 | 同一季节下陆地与海洋的温度变化；用颜色和温度变化示意条比较响应快慢 | 同样进入夏季或冬季，哪一侧温度变化更明显？ |
| ② 气柱响应与空气调整 | 夏季陆地较暖，展示气柱膨胀、上升及高空空气外流；冬季展示大陆冷却、下沉及相应空气调整。标明近地面和高空的比较高度 | 仅凭“暖、冷”还不能跳过空气运动，如何形成近地面气压差？ |
| ③ 大陆气压中心形成 | 夏季陆地近地面空气柱质量减少，出现热低压；冬季形成大陆冷高压。地球上的大陆气压异常逐渐增强 | 同一高度比较，哪一侧近地面气压较高？ |
| ④ 理想气压带被改变 | 地球从理想参考带渐变到区域气压分布；冬季突出亚洲高压对副极地低压带的影响，夏季突出亚洲低压对副热带高压带的影响 | 连续带状分布在哪些区域发生改变？ |
| ⑤ 近地面风与冬夏转换 | 先显示由高压指向低压的推动方向，再显示运动气流受偏向作用及摩擦影响后的斜穿等压线风向，最后归纳冬夏季风 | 气流由哪里吹向哪里？为什么最终风向不直接沿推动方向？ |

每个节点完成自动停顿；教师决定何时进入下一节点。温度、空气运动、H/L和完整风线按阶段出现，结果对照模式可直接显示全图。

### 3. 冬夏对照

机制完成后提供冬夏并排的简化剖面与气压分布摘要，也可在三维地球上来回切换。切换季节时保留比较区域；形成机制模式回到首节点等待开始，结果对照模式直接切换最终图。

夏季归纳为“大陆相对较暖—热低压—海洋气流进入大陆”；冬季归纳为“大陆相对较冷—冷高压—大陆气流流向海洋”。具体风向结合气压配置、半球与近地面受力解释。

### 4. 科学表达边界

- 明确温度差、气柱调整和空气质量变化的联系，不用“热空气轻所以地面低压”代替完整过程。
- 气压比较必须在同一高度；高空和近地面的高低压关系不能混用。
- 局部剖面用于解释热力作用，不把真实季风画成与昼夜海陆风完全相同的封闭小环流。标明季风的季节尺度和大范围背景。
- 海洋副热带高压等包含动力作用，不能把所有海洋气压中心都解释为海水冷暖的直接结果。
- 地转偏向作用改变运动方向，初始水平推动来自气压梯度；不把偏向作用画成下沉原因。

## 四、第五步：季风到降水与气候

### 1. 画面组织

保留全球展开图与城市气候图，增加随地点切换的局部机制图。三部分分工为：全球图看来源和路径，局部图看水汽与抬升，气候图看季节性结果。

点击城市后高亮与该城市有关的路径，其余风带淡化。水汽用沿气流移动的粒子或湿度色带表达，风向箭头与水汽标记采用不同形状，并提供文字图例。

### 2. 分阶段演示

| 节点 | 画面逐步出现什么 | 学生需要解释什么 |
|---|---|---|
| ① 判断来向与源区 | 高亮选定地点、源区和气流路线；先隐藏气候类型、全年结论与原因答案 | 风从大陆还是海洋来？可能带来怎样的温度和湿度条件？ |
| ② 水汽输送 | 海洋源区出现水汽示意，随气流输送至目标区域；冬季对照显示所选案例水汽条件较弱 | 风向如何影响水汽来源？ |
| ③ 抬升、冷却与凝结 | 显示与案例对应的辐合、锋面或地形抬升；空气上升冷却，条件满足后凝结形成云雨 | 水汽到达为什么不一定立即降雨？还需要什么过程？ |
| ④ 季节降雨与年变化 | 显示该季节的降雨结果，再突出气候图中的对应月份；比较另一个季节，归纳全年雨量分配和温度特征 | 地图过程怎样帮助解释气候图？哪些特征还需其他因素解释？ |

气候图是预设的教学示意资料，动画只与对应月份和特征建立解释联系，不按粒子数量计算降水，也不暗示单次降雨动画生成全年气候。

### 3. 地区差异

| 地区 | 主要演示 | 必须保留的区别 |
|---|---|---|
| 北京 | 冬季大陆气流与夏季海洋水汽输送，对照夏季降水集中 | 温度年变化还与纬度、太阳辐射等有关，不全由季风产生 |
| 上海 | 夏季水汽输送与锋面等抬升条件，冬夏雨量比较 | 冬季仍有降水；夏季降水受锋面、台风等影响，不将全年每月都简化为同一过程 |
| 孟买 | 印度洋水汽输送与迎风地形抬升，形成明显雨季 | 南亚夏季季风还涉及气压带北移和跨赤道气流；冬季西海岸相对干燥 |
| 达尔文 | 1月湿季、7月干季与当地风向对照 | 明确南半球季节，1月为当地夏季，不能把北半球月份标签直接套用 |

默认先完成一个案例，再开放其他地区的迁移比较，避免四个地点的信息同时堆积。

### 4. 南亚跨赤道机制

孟买夏季另设可展开的机制节点：

1. 展示气压带北移及南亚低压背景。
2. 显示南半球东南信风向赤道运动。
3. 气流跨过赤道后，突出北半球向运动方向右侧的偏向作用，逐渐成为西南气流。
4. 接入印度洋水汽输送与地形抬升节点。

跨赤道前后用分段箭头与方向参照表示，不在进入页面时一次画完全部路线。说明这是方向与机制示意，真实路径受多种因素影响。

## 五、两步统一的交互规则

- 提供“形成机制”和“结果对照”两种视图；引导教学进入形成机制，复习读图可直接使用结果对照。
- 复用前两步的上一节点、下一节点、暂停／继续、重播本节点与从头重播规则；默认每节点停顿，连续复习可自动推进。
- 首次进入节点先显示预测问题。解释按钮只显示当前节点的解释，后续原因、气候类型与全年结论按进度揭示。
- 第五步左侧预测与右侧答案统一控制；未揭示前，右侧不能提前显示同一问题的答案。气候读图任务可主动展示资料，但相应任务应改为“根据图判断原因”。
- 教师暂停和速度控制作用于全部机制动画、水汽与流动箭头；拖动地球或滚动地图仍可操作。
- 第四步进入第五步保留月份并选择相应案例；第五步返回第四步恢复原区域与进度。跨步返回时机制保持暂停。
- 完成节点后固定关键画面，下一节点再逐步增加新信息；切换月份或地区时明确重置机制进度，避免混合两种情境。

## 六、画面清晰度与信息层级

1. 海陆轮廓始终可辨，机制图与文字不覆盖关键地理区域；保留现有降低气压色块透明度的改进。
2. 一次突出一个因果环节；温度、气压、风向、水汽、降水使用稳定的颜色和形状语义，配文字标识，不能只靠颜色区分。
3. 显示高压到低压的推动方向时，与实际风向箭头明确区分；风名按来向命名，箭头表示吹向。
4. 投屏模式保留当前问题、关键图例与节点控制。小屏采用上下排列与局部滚动，按钮不遮挡机制图。
5. 继续标明温度、气压、路径、时间和气候资料为教学示意；动画时长不对应真实形成时长。

## 八、验收标准

### 教学内容

- 第四步不读解释文字，也能观察海陆温度响应、空气调整、气压差和风向形成的顺序。
- 冬夏切换可说明大陆冷高压与热低压的差别；理想带到区域分布的变化有明确定位。
- 第五步可区分气流路线、水汽输送和抬升条件；海洋来风不被直接等同于必然降雨。
- 孟买夏季能观察跨赤道前后风向变化及迎风地形降雨；达尔文的1月／7月季节对应正确。
- 年气候图与过程建立解释联系，未呈现为由动画实时算出的统计结果。

### 交互与功能

- 每个节点可独立推进、暂停、回退和重播；回退时后续图层与答案同步收起。
- 暂停冻结全部动态机制，速度调节一致；切换季节、地区或步骤不出现旧情境残留。
- 预测模式的文字、图层和结论显隐一致；结果对照模式可直接读完整图。
- 第四、第五步往返保持月份正确，进度与播放状态符合约定。
- 复核前三步、课堂探究、教师端、图层开关、快捷键和离线打开；新增检查覆盖节点顺序、答案显隐和冬夏／地区分支。
- 使用桌面、教室投屏及小窗口截图核对大陆轮廓、标签、控件和局部机制图的可读性；真实后排可读性由现场验收确认。

### 学生理解

用短任务检验，而不只验收按钮和动画：

1. 不看平台，解释夏季大陆热低压与近地面来风之间的联系，并补画冬季对应关系。
2. 在陌生的同高度气压图上区分推动方向与北／南半球近地面风向。
3. 解释同样有海洋水汽，为什么还要判断抬升条件；用孟买案例说明雨季原因。
4. 根据达尔文图判断1月与7月的当地季节，并说明湿季与气流来源的联系。

开放解释与作图由教师评议，记录典型误解后调整演示。程序验收与课堂理解验收分别记录，不将功能测试通过视为教学效果已经验证。

## 九、建议完成后的课堂路线

第三步理想结果 → 引入季节与真实海陆 → 第四步东亚形成机制 → 冬夏对照 → 第五步水汽与降雨案例 → 南亚特殊机制 → 达尔文迁移 → 独立解释与作图。

课时安排按班级基础选取，不要求一节课播放全部地区。核心完成标准是学生能解释“气压与风怎样形成”和“这些气流怎样影响降水”，再以完整地图和气候图归纳结果。

1. 陌生气压场：南半球

南半球同一水平面，上北下南、右东左西。西侧1000 hPa，东侧1016 hPa，等压线近似南北向。

画或描述气压梯度力和近地面风向，并写出推导依据。

2. 隐去地名的气候资料

甲站位于12.42°S。1月：28.3°C、468 mm；7月：24.8°C、0 mm。

判断当地季节及湿季月份；用气流来源、水汽和抬升条件解释，指出仅凭这些资料不能确定的内容。

3. 用反例检验“印度冬半年都少雨”

孟买（西海岸）：7月790.5 mm，11月8.8 mm。金奈（东海岸）：7月104.3 mm，11月381.1 mm。东北季风可经过孟加拉湾到达印度东南海岸。

材料是否支持上述概括？结合风的来向、海陆位置及其他降水条件解释两地差异。

4. 同纬度，降水能否相同？

乙、丙均在45°N。乙位于大陆西岸，西风先经过海洋；丙位于内陆山脉背风侧，距海约1500 km。

比较两地降水条件，并指出气压带风带模型能解释什么、还需要哪些材料。

5. 解释副热带高压，避免“冷才高压”

某地位于30°附近，近地面气压偏高，观测到下沉运动；下沉空气通常增温。

为什么不能用“当地冷却”概括这一高压？说明高空调整、下沉与近地面气压的关系，并解释30°的含义。

开放任务核对依据（教师使用，可裁下）

1. 陌生气压场：南半球
同一高度比较，推动方向向西；相对前进方向左偏，获得向南分量；近地面斜穿等压线，吹向西南、来自东北；能区分推动力、偏转与风向命名。

2. 隐去地名的气候资料
1月是当地夏季，7月是冬季；引用降水数值判断1月较湿；0.0为气候月平均显示值，不等于每年无雨；海洋水汽与辐合抬升共同影响湿季；不把单月降水或季风动画当作完整气候成因。

3. 用反例检验“印度冬半年都少雨”
引用金奈11月降水作为反例；辨别印度东西海岸及气流经过的海面；指出东北季风经过孟加拉湾可补充水汽；不把11月降水全部归因于单一因素；还可能受热带天气系统影响。

4. 同纬度，降水能否相同？
两地虽同纬度但海陆位置不同；乙的西风有海洋水汽来源；丙受距海远和背风坡影响，不能只凭西风判湿润；需要水汽、地形及实际降水资料检验。

5. 解释副热带高压，避免“冷才高压”
副热带高压在教材模型中主要属动力成因；联系高空空气调整与气柱质量收支；下沉可绝热增温，高压不等于当地寒冷；30°是近似位置，偏向力不直接向下压空气。

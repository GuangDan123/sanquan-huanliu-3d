# 课堂演示改进记录

日期：2026年10月10日。

本次根据对照视频的复核，优先改进了课堂可读性、节点操作和运行质量：

- 新增“课堂路线”，按“单圈形成→三圈推导→季节移动→海陆与季风→降水与气候→独立作图→迁移解释”推进；每一环节保留预测问题、上一环节、下一环节和退出路线。
- 三维关键节点增加“随节点聚焦”和“定位本节点”，教师可关闭自动聚焦并保留手动视角；教师锁定视角时不会被自动调整。
- 第四、第五步将播放、上一节点、下一节点、重播和从头重播集中到固定操作区；月份、地区和其他设置折叠到更多设置，避免挤压核心问题。
- 第四步未启用的粒子改用真正的逐点透明度，尾迹也按透明度衰减，不再以黑色像素覆盖地球；省电模式和粒子密度同时作用于新机制场。
- 第五步地图暂停或状态不变时停止重复绘制隐藏的三维场景，降低投屏和低端设备的无效占用。

## 第四步白色粒子的指示性修正

用户反馈白色粒子难以指示上升、下沉后，对默认亚洲视角进行了逐帧量测。气柱节点进度 25% 到 37.5%（0.5 秒）的连续位移多数仅约 0.6–1.3 像素。白色柔光点在浅色地表上对比不足，局地径向运动的屏幕投影又较短；单纯增大粒子不能充分解释方向。原来的寿命重置还会改变粒子经纬度，造成无关的随机跳动。

- 垂直粒子保持原经纬度，仅在高度边界循环，移除寿命导致的随机换位；每次循环清空旧尾迹，避免跨高度连线。
- 地球白色标记直径增至原来的 1.65 倍，使用实心白色与深色描边；近地面和高空粒子保留原尺寸。
- 气柱节点开始后显示“大陆局部侧视 · 垂直运动放大”，从当前启用的白色粒子抽取最多六个，直接使用它们的高度与历史；标出近地面、高空、当地竖直以及冬季下沉／夏季上升箭头。地球仍按当地径向运动，放大图不改变轨迹。
- 局部侧视图随播放、暂停、重播、月份、密度、省电、粒子及轨迹开关同步；形成机制关闭或返回前置节点时隐藏。静止时复用画面。

专项验证 `tools/verify-column-visibility.mjs` 通过 21/21，含实际冬夏运动方向、固定气柱、侧视图像素与地球粒子高度吻合、实时播放、暂停、重播、开关、省电、1366×768 和 390×844 可见性，以及结果模式隐藏。报告与截图见 `artifacts/column-final-20261010/`。

# 五步动画教学表达修改记录

本轮依据 `output/teaching-audit/五步动画教学表达评审.md`，按第二步、第三步、第四步、第五步、第一步的顺序修改。保留现有教学示意模型，将原先主要依赖解释文字的对比关系加入播放画面。

## 各步的变化

| 步骤 | 已修改的演示 | 学生需要从画面读出的关系 |
| --- | --- | --- |
| 1 理想单圈 | 加入两层同高度H/L对照、反向水平输送和空气量示意 | 高空从赤道向两极，近地面从两极返回；两层各自在气压差作用下运动 |
| 2 加入自转 | 正常播放保留原经线、前进与水平偏向箭头；两半球同时对照向北和向南运动；分开局部锋面与平均三圈 | 左右以气流前进方向为准；水平偏转不能直接解释下沉；冷空气在下方，暖空气沿其上方抬升 |
| 3 季节移动 | 在地球与局部图解上加入直射纬度、热力中心响应和固定37°N参照 | 两半球的带随季节整体南北移动；固定纬度在不同季节受不同带影响 |
| 4 海陆与季风 | 同步气柱侧视、共同高度线、可追踪输送份额和地面气压指示；球面粒子数同步 | 冷热变化先改变柱高，输送再改变柱内空气质量；地面气压变化对应空气质量变化 |
| 5 季风与气候 | 同一气团的抬升、降温、凝结指示；重画孟买山地风向、迎背风坡与主要雨区；气候图突出当前月份 | 水汽到达后还需抬升和冷却条件；迎风坡降雨较多；过程解释季节差异，全年曲线来自月统计资料 |

第二步27—30秒先解释局部暖空气抬升，31秒后再显示平均高纬上升支；镜头跟随暖空气支路，独立环流之间的镜头转移不绘制连接气流。

第三步使用37°N，是为使参照点落入本模型夏季北移后的副热带高压窄带内。太阳直射纬度在约23.44°N/S之间变化，带的位移沿用原模型的约±8°示意，两者不等比例。观察点用于固定纬度比较，当前均一地表模型不据此推断某个真实城市的气候。

第四步以48份示意空气追踪两柱和输送途中份额，保证总数守恒。柱高变化时份额不变，冬夏输送方向相反；这些份额不是空气质量的实际测量值。第五步的温度柱表达同一气团降温，不给出未经计算的真实温度或凝结高度。

## 显示与操作

桌面端局部图解默认展开，与原动画共享进度，可收起。小屏默认收起，点击“局部图解”后浮窗显示完整图解。暂停、拖动进度和冬夏对照都沿用原控件。离开相应步骤、隐藏标注或进入课堂探究时，相关浮层与地球标记同步隐藏。

## 一、作品概述

### 1.1 一句话定位

一个**离线可运行**的浏览器三维教学工具：把高中地理最难讲清的"三圈环流"，用可旋转、可分步、可调参的三维模型还原成一条**能被看懂的推导链条**，并用配套的二维补图练习完成从三维观察到二维图示的认知闭环。

### 1.2 解决什么问题

三圈环流是高中地理"气压带和风带"的核心内容，也是公认的教学难点。它的困难不在名词，而在**四重空间关系同时成立**：

1. 垂直运动（上升 / 下沉）与水平运动（近地面 / 高空）方向相反；
2. 近地面气流与高空气流方向相反；
3. 同一纬度带的南北半球偏转方向相反；
4. 环流圈、气压带、风带三者位置对应但名称各异。

传统教学依赖教材剖面图、板书和二维动画。学生必须在头脑中自行完成"平面 → 球面""静态 → 动态"的双重心理转换——**这部分负荷与知识本身无关，却占用了本该用于理解机制的工作记忆**。结果是很多学生只能背下"哈德莱、费雷尔、极地"三个名字，说不清它们为什么是这样分的。

### 1.3 我们的做法

不额外增加信息量，而是**把推导过程本身变成一个可以操作的时序**：

| 认知难点 | 本作品的做法 |
|---|---|
| 气流的立体闭合路径看不见 | 三维管道 + 管内流动条纹 + 粒子流，方向可直读 |
| "三圈如何形成"讲不清 | 手动呈现高空偏转、30°下沉分流、60°辐合抬升，再归纳三圈；不把单圈机械折裂 |
| 环流圈、气压带、风带三者混成一团 | 图层独立开关：默认只显示环流，需要时再叠加气压带与风带箭头 |
| 三维看懂了，二维图还是不会画 | **图示回归模块**：拖拽标签补全剖面图，即时判分 |
| 学生水平参差 | 引导模式（手动分步 + 预测问题）与自定义模式（调示意弯曲与显示参数）双路径 |
| 机房设备弱、网络不稳 | 依赖全本地化，**断网双击即用**；提供省电模式 |

## 二、功能与界面

### 2.1 三步递进演示（核心）

| 步骤 | 呈现内容 | 设计意图 |
|---|---|---|
| 第一步 · 理想单圈环流 | 假设地球不自转，赤道上升、极地下沉，单一闭合环流；高空段橙色、近地面段蓝色。进入时弹出文字说明弹窗，气流暂停等待阅读 | 先建立"热力差异驱动大气运动"的基本认知，剥离干扰变量 |
| 第二步 · 地转偏向力介入 | 四个手动环节：高空向极地偏转 → 30°积聚下沉与分流 → 60°冷暖交汇、暖空气上升 → 三圈归纳。每环节先预测，可展开解释并前后切换；不自动串场 | 教材理想模型示意，非动力数值模拟 |
| 第三步 · 三圈环流成型 | 归纳哈德莱（橙）、费雷尔（黄）、极地（蓝）三圈，叠加七个气压带与六个风带。**不弹窗**，自动开启气压带图层 | 完成从机制到结论的收束，与教材图示对齐 |

> 界面设计说明：第二、三步取消模态弹窗，是为了让三维画面始终不被遮挡——原理解读改由左侧常驻知识点面板承担，
> 教师可边讲边对照画面，也便于录制演示视频。

#### 第二步视觉与面板文案的对应关系

| 环节 | 画面与解释 |
|---|---|
| 高空偏转 | 南北半球向极地运动的高空气流都逐渐具有东向分量；北半球右偏、南半球左偏 |
| 30°下沉分流 | 先预测，再播放约12秒的过程：示踪气流汇入与积聚 → 逐段下沉 → 到达地面形成高压 → 向赤道与高纬分流 → 最后呈现哈德莱圈；支持暂停、继续、从头重播 |
| 60°交汇上升 | 播放约10秒的过程：冷暖气流辐合 → 较暖空气沿较冷空气上方抬升 → 副极地低压与高纬圈归纳。局部剖面同步显示，可暂停与重播；完整高纬圈在最后才出现 |
| 三圈归纳 | 此时才呈现费雷尔完整圈，解释其热力间接环流性质 |

三维参考模型假设地表性质均匀；季节移动及海陆影响另在“课堂探究”中比较。30°和60°为近似纬度，环流高度与气流路径经过示意化处理。播放速度控制粒子与教学过程，地表转动仅控制贴图，“示意弯曲”仅改变箭头弯曲幅度，不用于推演真实自转速度与环流圈的关系。

预设视角与鼠标观察围绕实际地球中心；视角按知识面板、控制栏和练习面板的可用空间取景。关闭机制路径时同步关闭对应标注。

### 2.2 交互功能

- **视角**：俯视 / 侧视 / 平视 / 重置；鼠标拖拽旋转、滚轮缩放
- **图层**：网格、粒子、轨迹、气压带、标注、图例 6 路独立开关
- **显示参数**：播放速度、示意弯曲（0–45°）、地表转动与粒子密度可调；不构成大气动力模型
- **知识查询**：点击环流圈、图例或气压带标签，弹出对应知识点卡片
- **教师端**：播放 / 暂停、步骤跳转、锁定视角、教师手动机制演示
- **录屏辅助**：按 `H` 一键隐藏全部 UI，只保留纯净三维画面
- **性能**：省电模式适配弱设备

### 2.3 图示回归练习

右侧面板用 Canvas 2D 绘制环流剖面图，提供 13 个可放置区域（7 个气压带 + 6 个风带）与 10 个随机排序、可重复使用的标签，支持拖拽、点击选择后放置及键盘操作，学生完成补图后点击"检查答案"分别统计正确、错误与未完成，保留标签文字并附 ✓ / ✗ 反馈；答案在关闭后重新打开面板时保留。在三维场景中打开任一知识点时，二维图对应区域同步闪烁高亮，**帮助学生建立"三维所见 ↔ 二维所画"的对应关系**。

### 2.4 课堂探究与投屏

左上“课堂探究”提供风的成因、六个风带、季节移动、海陆与季风、标准剖面、理解练习、气候应用七个主题。气压梯度力、偏向力与摩擦按顺序说明；六个风带由高低压、初始流向、偏转及来向命名逐一推导。季节图区分直射点与气压带位置，海陆图比较冬夏气压中心、东亚季风和南亚跨赤道气流。标准剖面采用横向纬度、纵向高度，可按半球与关键纬度观察并返回三维。

14道理解题检查成因、方向、季节与应用，提供统计、解释与相关演示回看；另有迁移作答与四点评议依据，由师生讨论评分。关闭重开保留本页会话内的作答，刷新不持久化。探究打开时暂停背景三维过程，播放与导航固定，支持键盘及小屏滚动。投屏模式放大文字、淡化干扰并扩大图示。所有图示为教学概念模型，不是实测地图或数值求解结果。

## 三、技术实现

### 3.1 技术栈

| 项目 | 实现 |
|---|---|
| 3D 引擎 | Three.js r152（本地化部署） |
| 运行形态 | 纯前端单页应用，无后端、无数据库 |
| 依赖 | 零 CDN，全部随作品包分发；地球纹理以 base64 内嵌 |
| 规模 | 单文件约 3100 行（HTML + CSS + 原生 JavaScript） |
| 许可 | MIT License（第三方组件 Three.js 同为 MIT） |

> 详细实现说明（含算法、性能数据采集方法、与论文的一致性核对表）见 `docs/技术说明.md`。

### 3.2 关键技术点

1. **机制与归纳模型分开呈现**：单圈路径与三圈路径为预制教学示意，第二步通过手动状态控制逐段展示机制箭头与环流圈，不进行动力求解或按时间淡入淡出推演。
2. **着色器驱动的流动感**：管道材质为自定义 `ShaderMaterial`，沿管道周向生成随时间移动的明暗条纹，气流的**方向**因此可以直接读出，无需依赖箭头逐个建模。
3. **三级纹理降级**：内嵌 base64 卫星纹理 → 外部卫星贴图 → 程序化 Canvas 纹理。任一环节失败作品仍可完整运行，保证课堂现场的鲁棒性。
4. **不产生逐帧 GC 的动画**：粒子颜色使用 65 级查找表（LUT）与复用的临时 `Color` 对象，避免每帧新建对象造成的卡顿。
5. **标签背面剔除**：CSS2D 标签通过相机到锚点的线段与实际地球中心检测遮挡，背面标注自动隐藏，避免文字穿透球体造成误读。

## 四、教学应用设计

### 4.1 课时安排（高中地理"气压带和风带"，1 课时）

| 环节 | 时长 | 教师活动 | 学生活动 |
|---|---|---|---|
| 情境导入 | 3 min | 打开第一步，提问"若地球不自转，大气如何运动？" | 预测气流方向 |
| 单圈环流建构 | 5 min | 侧视分步呈现，节点处暂停追问 | 描述气流路径，绘制简图 |
| 偏转介入 | 5 min | 切到第二步，引导逐环节预测、解释30°下沉与60°抬升 | 比较前后差异，解释成因 |
| 三圈成型 | 6 min | 切到第三步，打开气压带图层 | 定位七个气压带、六个风带 |
| 图示回归 | 8 min | 打开图示回归面板，巡视指导 | 拖拽补全剖面图，自查订正 |
| 分层探究 | 10 min | 基础组用引导模式完成任务单；进阶组切自定义模式调参 | 比较机制箭头与风向，解释模型假设 |
| 归纳巩固 | 3 min | 组织板图总结 | 说出完整因果链条 |

### 4.2 两种学习路径

- **引导模式**（面向基础薄弱学生）：教师按“受热不均 → 单圈环流 → 高空偏转 → 30°下沉分流 → 60°交汇抬升 → 三圈归纳”手动推进，左侧面板提供预测问题及可展开解释；
- **自定义模式**（面向学有余力学生）：开放示意弯曲、地表转动与粒子密度等显示参数，比较箭头与近地面风向；不用于推演真实自转速度改变后的环流。

## 五、创新点

1. **分步机制建构**：在单圈假设与三圈归纳之间，提供高空偏转、30°下沉分流、60°交汇抬升及三圈归纳四个可暂停、可回溯的机制节点。
2. **三维—二维图示回归闭环**：多数三维教学资源止步于"看得更清楚"，本作品进一步用拖拽补图 + 即时判分把观察结果强制转化为二维表达能力，直击"看懂了但不会画"的真实痛点。
3. **方向与空间关系可视化**：高空气团动态偏转，与沿经线的无偏转参考比较；随气团移动的偏向箭头及同步俯视图表达北半球右偏、南半球左偏，支持暂停与重播。近地面和垂直气流用方向箭头呈现，三圈颜色与近地面风向分别表达剖面归纳和球面流向。过程、箭头长度与弯曲幅度为教学示意。
4. **面向真实课堂的工程鲁棒性**：零 CDN、三级纹理降级、省电模式、`?state=` 固定入口、`H` 键纯净录屏——都是针对机房弱网、设备性能参差、教师需要快速进入指定教学环节等真实约束做的设计。

## 六、局限与后续计划

**已知局限（如实说明）**

- 呈现的是**理想化概念模型**（地表均一、不考虑海陆分布与季节移动），不用于精确模拟真实大气环流；
- 目前仅覆盖三圈环流一个知识点，尚未提供其他知识模块；
- 教师端为同一页面内的本地控件，**不含班级管理、学生账号与学习行为数据采集**功能；
- 教学效果尚缺真实课堂数据支撑（见 4.3）。

**后续计划**

- 补充真实课堂试用与前后测数据；
- 基于同一套参数化曲线框架扩展洋流、地球运动（黄赤交角）等模块，验证设计范式的可迁移性；
- 增加学习行为记录（视角切换、停留时长、参数调试次数）以支持学习分析；
- 探索接入 WebXR，提供沉浸式观察模式。

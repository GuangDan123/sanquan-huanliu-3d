## 一、作品概述

### 1.1 一句话定位

一个**离线可运行**的浏览器三维教学工具：把高中地理最难讲清的"三圈环流"，用可旋转、可分步、可调参的三维模型还原成一条**能被看懂的推导链条**，并用配套的二维补图练习完成从三维观察到二维图示的认知闭环。

### 1.2 解决什么问题

三圈环流是高中地理"气压带和风带"的核心内容，也是公认的教学难点。它的困难不在名词，而在**四重空间关系同时成立**：

1. 垂直运动（上升 / 下沉）与水平运动（近地面 / 高空）方向相反；
2. 近地面气流与高空气流方向相反；
3. 同一纬度带的南北半球偏转方向相反；
4. 环流圈、气压带、风带三者位置对应但名称各异。

传统教学依赖教材剖面图、板书和二维动画。学生必须在头脑中自行完成"平面 → 球面""静态 → 动态"的双重心理转换——**这部分负荷与知识本身无关，却占用了本该用于理解机制的工作记忆**。结果是很多学生只能背下"哈德莱、费雷尔、极地"三个名字，说不清它们为什么是这样分的。

### 1.3 我们的做法

不额外增加信息量，而是**把推导过程本身变成一个可以操作的时序**：

| 认知难点 | 本作品的做法 |
|---|---|
| 气流的立体闭合路径看不见 | 三维管道 + 管内流动条纹 + 粒子流，方向可直读 |
| "单圈为什么会分成三圈"讲不清 | 分步演示：第二步让环流带在球面上真实弯折并标出 30° 弯折节点、用一排黄色箭头量化"偏向力随纬度增强"，再过渡到三圈 |
| 环流圈、气压带、风带三者混成一团 | 图层独立开关：默认只显示环流，需要时再叠加气压带与风带箭头 |
| 三维看懂了，二维图还是不会画 | **图示回归模块**：拖拽标签补全剖面图，即时判分 |
| 学生水平参差 | 引导模式（自动分步 + 观察任务）与自定义模式（调偏转角、自转速度）双路径 |
| 机房设备弱、网络不稳 | 依赖全本地化，**断网双击即用**；提供省电模式 |

## 二、功能与界面

### 2.1 三步递进演示（核心）

| 步骤 | 呈现内容 | 设计意图 |
|---|---|---|
| 第一步 · 理想单圈环流 | 假设地球不自转，赤道上升、极地下沉，单一闭合环流；高空段橙色、近地面段蓝色。进入时弹出文字说明弹窗，气流暂停等待阅读 | 先建立"热力差异驱动大气运动"的基本认知，剥离干扰变量 |
| 第二步 · 地转偏向力介入 | **核心是一个约 3 秒的连续演变**：①环流带先在球面上被"折弯"（高空向极地流动段东偏、近地面向赤道流动段西偏，经度偏移峰值约 4.2°）；②30°N/S 浮现"气流堆积下沉"弯折节点；③随后单圈环流带逐渐淡出，**哈德莱、费雷尔、极地三圈依次浮现**（中纬费雷尔环流出现得最晚、最淡，观感是"被两侧夹出来"，与其成因一致）；④右侧沿经圈排列**偏向力强度指示**（0°→0%、15°→26%、30°→50%、45°→71%、60°→87%、75°→97%、90°→100%，赤道档仅留零位基准）；⑤北极上方显示**自转方向指示**（俯视逆时针）。**不弹窗**，直接进入动态演示 | 第二步不能只是"多几个箭头标注"，而应让**环流形态真的被偏向力改造成三圈**——把"单一环流带出现弯折节点，酝酿分化为三圈"变成可见的演变过程 |
| 第三步 · 三圈环流成型 | 分裂为哈德莱（橙）、费雷尔（黄）、极地（蓝）三圈，叠加七个气压带与六个风带。**不弹窗**，自动开启气压带图层 | 完成从机制到结论的收束，与教材图示对齐 |

> 界面设计说明：第二、三步取消模态弹窗，是为了让三维画面始终不被遮挡——原理解读改由左侧常驻知识点面板承担，
> 教师可边讲边对照画面，也便于录制演示视频。

#### 第二步视觉与面板文案的对应关系（设计核对表）

左侧知识点面板的每一条，都能在三维画面中找到对应物：

| 面板文案 | 对应的三维呈现 |
|---|---|
| "产生地转偏向力：北半球右偏、南半球左偏" | 南北半球环流带向相反方向弯折；北极上方自转方向指示 |
| "偏向力在赤道为零、向两极逐渐增大（注意观察黄色箭头长度变化）" | 沿经圈排列的黄色强度条 + 百分比标注，自 0% 递增到 100%；赤道档长度≈0，只留零位基准圈与"偏向力 0%"标注 |
| "30° 纬度高空气流偏转成西风、前进受阻→堆积下沉" | 30°N/S 处的发光节点、指向地心的下沉箭头、"气流堆积下沉"标注 |
| "单一环流带在 30°、60° 出现弯折节点，即将分裂为三圈" | 环流带先在球面上**真实弯折**（不再是平面椭圆），随后单圈带淡出、三圈依次浮现，**演变本身**就是这个结论的呈现 |

> **实现要点**
> - 偏转位移只在**水平气流段**产生（上升/下沉段保持竖直），且按 |sin(纬度)| 加权 —— 因此赤道附近几乎不偏、中高纬明显偏移。
> - "单圈 → 三圈"是**形态演变**而非叠加标注：`STATE.morph` 由 0 推进到 1，单圈带透明度 `1-e`、三圈环流按不同幂次浮现；
>   中纬费雷尔环流幂次更大（浮现更晚、中间阶段更淡），观感上由两侧环流"夹出"，与其热力间接环流的成因一致。
> - 第一步是"地球不自转"的理想模型，因此**不出现任何偏向力相关标注**（强度指示、自转方向、弯折节点均隐藏）。
> - **标签贴附视轮廓**：所有纬度、气压带、风带标签都放在"地球在屏幕上的边缘"外侧（半径 `R+2.4`，在大气层之外），
>   并随相机方位每帧重算。这样旋转视角时标签始终环绕地球外侧，不会压住环流圈，也不会被球体遮挡。
> - **环流剖面屏幕锚定**：环流带（单圈 / 三圈）与第二步弯折节点同挂 `crossSectionRoot`，根部每帧按相机方位反向旋转
>   （`updateCrossSectionFacing`），使剖面始终停在地球的**屏幕左侧**、与左侧纬度标尺同侧。
>   此前剖面固定在世界经度 0（+X 侧），默认相机方位下会落到画面右侧——"重启后环流圈在右边"即由此而来。
>   现在四种预设视角（重置 / 侧视 / 平视 / 俯视）下剖面都在左侧，且经量测不被球体遮挡（`tools/verify-cross-section.mjs`）。

### 2.2 交互功能

- **视角**：俯视 / 侧视 / 平视 / 重置；鼠标拖拽旋转、滚轮缩放
- **图层**：网格、粒子、轨迹、气压带、标注、图例 6 路独立开关
- **参数**：播放速度、偏转角（0–45°）、自转速度、粒子密度可实时调节
- **知识查询**：点击环流圈、图例或气压带标签，弹出对应知识点卡片
- **教师端**：播放 / 暂停、步骤跳转、锁定视角、演示模式自动串场
- **录屏辅助**：按 `H` 一键隐藏全部 UI，只保留纯净三维画面
- **性能**：省电模式适配弱设备

### 2.3 图示回归练习

右侧面板用 Canvas 2D 绘制环流剖面图，提供 13 个可放置区域（7 个气压带 + 6 个风带）与 10 个随机排序的可拖拽标签，学生完成补图后点击"检查答案"即时得到 ✓ / ✗ 反馈。在三维场景中打开任一知识点时，二维图对应区域同步闪烁高亮，**帮助学生建立"三维所见 ↔ 二维所画"的对应关系**。

## 三、技术实现

### 3.1 技术栈

| 项目 | 实现 |
|---|---|
| 3D 引擎 | Three.js r152（本地化部署） |
| 运行形态 | 纯前端单页应用，无后端、无数据库 |
| 依赖 | 零 CDN，全部随作品包分发；地球纹理以 base64 内嵌 |
| 规模 | 单文件约 3100 行（HTML + CSS + 原生 JavaScript） |
| 许可 | MIT License（第三方组件 Three.js 同为 MIT） |

> 详细实现说明（含算法、性能数据采集方法、与论文的一致性核对表）见 `docs/技术说明.md`。

### 3.2 关键技术点

1. **参数化环流曲线**：环流的纬度与高度均由路径参数 `t` 的正弦函数生成，使"单圈 → 三圈"的形态变化可在同一套曲线框架内连续插值，而非两套模型硬切换——这是三步过渡动画能做得平滑的技术基础。
2. **着色器驱动的流动感**：管道材质为自定义 `ShaderMaterial`，沿管道周向生成随时间移动的明暗条纹，气流的**方向**因此可以直接读出，无需依赖箭头逐个建模。
3. **三级纹理降级**：内嵌 base64 卫星纹理 → 外部卫星贴图 → 程序化 Canvas 纹理。任一环节失败作品仍可完整运行，保证课堂现场的鲁棒性。
4. **不产生逐帧 GC 的动画**：粒子颜色使用 65 级查找表（LUT）与复用的临时 `Color` 对象，避免每帧新建对象造成的卡顿。
5. **标签背面剔除**：CSS2D 标签通过世界坐标与相机位置点积判断朝向，地球背面的标注自动隐藏，避免标注穿透球体造成误读。

## 四、教学应用设计

### 4.1 课时安排（人教版必修一"气压带和风带"，1 课时）

| 环节 | 时长 | 教师活动 | 学生活动 |
|---|---|---|---|
| 情境导入 | 3 min | 打开第一步，提问"若地球不自转，大气如何运动？" | 预测气流方向 |
| 单圈环流建构 | 5 min | 侧视分步呈现，节点处暂停追问 | 描述气流路径，绘制简图 |
| 偏转介入 | 5 min | 切到第二步，引导观察 30°/60° 节点与箭头长度变化 | 比较前后差异，解释成因 |
| 三圈成型 | 6 min | 切到第三步，打开气压带图层 | 定位七个气压带、六个风带 |
| 图示回归 | 8 min | 打开图示回归面板，巡视指导 | 拖拽补全剖面图，自查订正 |
| 分层探究 | 10 min | 基础组用引导模式完成任务单；进阶组切自定义模式调参 | 比较不同偏转角下的环流形态 |
| 归纳巩固 | 3 min | 组织板图总结 | 说出完整因果链条 |

### 4.2 两种学习路径

- **引导模式**（面向基础薄弱学生）：系统按"受热不均 → 单圈环流 → 地转偏向 → 三圈环流 → 气压带风带"的因果链分步推进，在关键节点暂停并弹出观察问题；
- **自定义模式**（面向学有余力学生）：开放偏转角、自转速度、粒子密度等参数调试，支持推演特殊情境（如"若地球自转加快，环流会怎样"）。

## 五、创新点

1. **认知负荷导向的"分步推导"设计**：不是把三维模型当作更炫的插图，而是把"单圈 → 偏转 → 三圈"拆成三个可暂停、可回溯的认知节点，让抽象因果链获得可视化的时间结构。
2. **三维—二维图示回归闭环**：多数三维教学资源止步于"看得更清楚"，本作品进一步用拖拽补图 + 即时判分把观察结果强制转化为二维表达能力，直击"看懂了但不会画"的真实痛点。
3. **把物理规律转译为可度量的视觉变量**：地转偏向力随纬度增强 → 偏转箭头长度递增；环流分化 → 管道颜色三段渐变。学生可直接"读出"规律，而非被口头告知。
4. **面向真实课堂的工程鲁棒性**：零 CDN、三级纹理降级、省电模式、`?state=` 固定入口、`H` 键纯净录屏——都是针对机房弱网、设备性能参差、教师需要快速进入指定教学环节等真实约束做的设计。

## 六、局限与后续计划

**已知局限（如实说明）**

- 呈现的是**理想化概念模型**（地表均一、不考虑海陆分布与季节移动），不用于精确模拟真实大气环流；
- 目前仅覆盖三圈环流一个知识点，尚未提供其他知识模块；
- 教师端为同一页面内的本地控件，**不含班级管理、学生账号与学习行为数据采集**功能；
- 教学效果尚缺真实课堂数据支撑（见 4.3）。

**后续计划**

- 补充真实课堂试用与前后测数据；
- 基于同一套参数化曲线框架扩展洋流、地球运动（黄赤交角）等模块，验证设计范式的可迁移性；
- 增加学习行为记录（视角切换、停留时长、参数调试次数）以支持学习分析；
- 探索接入 WebXR，提供沉浸式观察模式。

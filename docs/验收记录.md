## 复现

在项目根目录运行：

```text
node tools/build.mjs
node tools/check-script.mjs 三圈环流3D交互式教学平台.html
node tools/serve.mjs 8123
```

保留服务运行，在另一终端运行：

```text
node tools/verify-acceptance.mjs http://127.0.0.1:8123/ artifacts/acceptance
node tools/verify-lessons.mjs http://127.0.0.1:8123/ artifacts/lessons
node tools/verify-lessons.mjs http://127.0.0.1:8123/ artifacts/lesson-layout --layout
```

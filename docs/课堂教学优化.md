# 气压带与风带：课堂教学优化与使用建议

本轮按高中地理课堂的知识顺序、常见误解及读图要求完善平台。对应旧版人教必修1第二章第二节、新版人教选择性必修1第三章第二节；气候应用按教材安排作为本节应用或下一节过渡。

| 原有问题与教学原因 | 已落实的改进 | 课堂入口 |
|---|---|---|
| 固定纬度容易被记成永久边界，无法解释季节控制变化 | 春秋分、6月、12月对照，直射点与各带位置分别显示，位移幅度不同 | 课堂探究—季节移动 |
| 均匀地表模型无法衔接现实气压分布及季风 | “加入海陆差异”独立按钮直接切换并播放，支持返回理想模型；冬夏气压中心、东亚与南亚季风对照 | 海陆与季风 |
| 学生易把自转当作风的直接动力 | 按气压梯度力推动、地转偏向力改变方向、近地面摩擦影响风向呈现 | 风的成因 |
| 30°下沉易被误解为偏向力直接向下压空气 | 强调近似位置与教材简化，删除“突然受阻”的机械解释 | 第二步环节2及成因练习 |
| 60°静态箭头不足以分辨动力抬升与当地受热 | 可播放辐合—暖空气沿冷空气上方抬升—低压及高纬圈归纳，并配局部剖面 | 第二步环节3 |
| 高空偏转难以直接迁移到六个近地面风带 | 逐风带选择高低压、初始流向、偏转与来向命名 | 六个风带 |
| “夹持形成中纬圈”“高空风必然相反”等文字易产生误解 | 修改知识卡，限定回流关系；强度标尺注明相同风速、非实测力值 | 知识卡与强度标尺 |
| 非标准展开图难以迁移到教材读图与作图 | 横向纬度、纵向高度剖面，可分半球、高亮关键纬度并返回三维 | 标准剖面 |
| 填对名称不能证明理解机制 | 14题覆盖成因、方向、季节与应用；错误解释、相关演示回看及迁移任务 | 理解练习 |
| 气压带与风带尚未用于地理现象解释 | 赤道多雨、副热带通常少雨、地中海冬雨夏干的解释链 | 气候应用 |
| 投屏字体与多图层干扰影响全班观察 | 投屏模式、固定播放与导航区、淡化太阳光线，使用低纬/中纬/高纬基础名称 | 左上投屏模式 |

## 建议教学顺序

1. 用“风的成因”复习同一水平面的气压差与水平运动，学生先说出风的直接动力。教师分步播放推动、偏转和摩擦，每步自动停住，讲解后点“下一步”；需要对照时回退或重播本步。
2. 返回三维，按单圈假设—高空偏转—30°下沉分流—60°辐合抬升—三圈归纳推进。每段先预测，再播放，必要时暂停让学生说明依据。
3. 进入“六个风带”，由学生推导东北信风与南半球盛行西风，特别区分吹向和来向。
4. 用“标准剖面”对应三维，遮住名称让学生画出四个关键纬度的垂直运动与近地面风向，再做原有13处补图。
5. 对照季节移动、海陆气压中心及两区域季风，避免把理想带状分布当成实际全年分布。
6. 用“理解练习”检查常见误解，再用气候应用与开放迁移题检验解释能力。可以分两课时完成，避免在一课时集中展示全部内容。

## 模型边界与教学验证

30°、60°是近似位置；环流高度、气压带宽度、位移幅度与动画时间经过示意化处理。海陆图是位置关系简图，风的受力箭头不是数值结果。直射点位置不能等同于赤道低压带位置，真实环流还有海陆、地形、季节滞后及天气尺度涡旋等影响。

功能验收覆盖实际播放、暂停、重播、方向、判分、视口、键盘与离线入口；尚未进行真实课堂前后测。开放迁移题由师生依据四个要点评议，不自动评分。建议课堂收集学生的无提示剖面图、风向推导与季节应用解释，作为进一步优化的证据。

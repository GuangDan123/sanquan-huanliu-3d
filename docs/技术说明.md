## 3. 核心算法说明（可作为"原创性"论证素材）

本作品的原创点集中在**"把地理推导逻辑翻译成三维几何与交互时序"**，而不是底层图形算法。这一点应当主动、诚实地写清楚：

### 3.1 环流路径参数化（原创）
`CirculationPathCurve.getPoint(t)` 不依赖美术建模，而是用**纬度 + 高度**两个正弦参数生成闭合环流管：

```
lat = midLat ± latRange · sin(2πt)      // 纬度在上升点与下沉点之间往复
alt = midAlt − altRange · sin(2πt)      // 高度在近地面与高空之间往复
```

配合 `getSingleDropPosition` / `getThreeCellDropPosition` 两套参数化，使**"单圈 → 三圈"的形态变化可以在同一套曲线框架内以连续参数插值完成**，而不是两套独立模型硬切换——这是"三步递进"能做出平滑过渡动画的技术基础。

### 3.2 偏转可视化（原创）
`createCoriolisVisuals()` 在 30°、60° 纬度生成"弯折节点 + 偏转力箭头"，箭头长度随纬度增大而增长，把"地转偏向力随纬度增强"这一**抽象规律变成可度量的视觉变量**；节点以 `easeOutBack` 缓动浮现/收缩，服务第二步的认知节奏。

### 3.3 色彩编码与三段渐变（原创）
管道 shader 内按路径参数 `uGradient` 在**哈德莱橙 / 费雷尔黄 / 极地蓝**三色间平滑过渡，第二、三步的"单圈带正在分裂为三圈"因此可被直接观察。相应地在 CPU 侧维护了 `_segLUT`（65 级颜色查找表）与 `_tmpColor` 复用对象，保证着色与粒子同步且**不产生逐帧 GC**。

### 3.4 三维—二维图示回归闭环（原创，最具教学价值的模块）
`drawDiagram()` 用 Canvas 2D 重绘环流剖面图，`DIAGRAM_ZONES` 定义 13 个可放置区域（7 个气压带 + 6 个风带），与三维场景通过 `ZONE_TO_KNOWLEDGE` 建立映射：在 3D 中点击知识卡片时，二维图对应区域同步闪烁高亮。**这个"三维观察 → 二维补图 → 判分反馈"的闭环是本作品区别于普通三维演示课件的核心设计。**

## 3. 核心算法说明（可作为"原创性"论证素材）

本作品的原创点集中在**"把地理推导逻辑翻译成三维几何与交互时序"**，而不是底层图形算法。这一点应当主动、诚实地写清楚：

### 3.1 归纳路径与机制箭头
`getSingleDropPosition` 生成单圈示意路径，`getThreeCellDropPosition` 以纬度和高度的椭圆参数生成三圈剖面。三圈路径为预制理想模型，保持剖面经度不变，近地面风向由独立风带箭头表达。没有数值求解大气动力，也不以形态插值推导三圈形成。

第一步由 `SINGLE_FLOW_STAGES` 统一定义上升、高空输送、极地下沉和近地面回流四段边界及解释时序。极地下沉保持90°纬度并降低径向高度，高空输送不提前落到近地面；箭头高亮与实际路径使用同一阶段定义。教师播放与局部播放都能启动、继续或重播当前过程。

`applyParticleSettings` 保留完整粒子缓冲，按密度与省电计算活动粒子数量；绘制范围、逐帧位置和颜色更新数量同步，退出省电可恢复当前密度，暂停状态也同步条纹及材质尺寸。未声称释放缓冲内存或实现几何LOD。

`createMechanismVisuals` 用 `CatmullRomCurve3` 和 `TubeGeometry` 绘制第二步的开放气流路径。其球面经度与近地面风带共用东经为负 theta 的坐标约定：高空向极地流动有东向分量，信风和极地东风有西向分量，盛行西风有东向分量；两半球在60°附近辐合。

### 3.2 教师手动控制
`MECHANISM_STAGES` 提供四环节的预测、观察和解释；`setMechanismStage` 与 `applyMechanismVisual` 控制对象显隐。主环节由教师手动切换，不自动串场。

首环节约10秒，`updateCoriolisDemo` 沿高空曲线移动两半球气团，逐段展开轨迹并保留沿经线的灰色虚线参考。以瞬时切线在当地水平面上的投影为速度方向，北半球偏向方向取 `v×r`，南半球取反，始终垂直于速度及当地径向；箭头长度按纬度正弦示意增强。`drawCoriolisComparison` 同步绘制上北下南、右东的两半球俯视对照图，帮助理解向北右偏与向南左偏均积累东向分量。两幅图随过程暂停、继续与重播；示意弯曲为0时轨迹沿经线，偏向箭头关闭。路径及时间是教学预设，未积分求解运动方程。

30°环节内另有约12秒的过程演示：汇入、积聚、下沉、近地面分流、低纬环流归纳。`STATE.mechanismDemo` 保存时间与播放状态，`updateSubtropicalDemo` 按时间设置管道的 `drawRange`，移动示踪粒子并增大高空积聚粒子群；地面高压与两支分流先后出现，低纬完整圈仅在最后归纳时显示。60°环节由 `updatePolarDemo` 在约10秒内呈现冷暖气流辐合、逐段抬升、低压与高纬圈归纳，并同步局部冷暖剖面；高纬完整圈在最后才出现，中纬完整圈留至第四环节。局部及教师端均可暂停、继续、重播；完成后不进入下一环节，回退重入重置。时间、高度及轨迹均为教学示意。

课堂探究独立维护 `LESSON_STATE`，由 `src/lesson.js` 与 `src/lesson.css` 实现，并经 `tools/build.mjs` 内嵌，不引入外部运行时请求。七个主题覆盖气压梯度力、偏向力、摩擦、六个近地面风带、季节移动、海陆气压中心及季风、标准纬度—高度剖面、理解练习与气候应用。季节图采用各纬度不同的预设位移，并单独表示直射点；海陆简图与跨赤道气流、标准剖面均为概念示意，不是观测图或数值模拟。

季节播放区采用两种模式：季节按钮按当前示意位置到指定季节插值；直接播放或重播采用约16秒的春、夏、秋、冬、春完整循环。`seasonMode` 区分两者，循环分四段平滑改变位移值，并同步按钮与阶段提示。避免春秋分起点与目标同为0，或重入已到达季节时仅有进度条变化的空播放。

风的成因以 `LESSON_PRESSURE_STEPS` 定义三个步骤，`pressureStep` 独立于累计时间控制当前图示。每步动画只推进到本步终点并暂停，避免恰好到边界时提前显示下一步；“下一步”在初始或中途暂停时启动/继续本步，本步完成后开始下一步，播放中及全部完成后禁用，避免连续点击跳过步骤。“上一步”暂停并恢复前一步完整画面。支持本步重播、从头逐步重播及中途暂停继续，操作区显示当前步骤和本步进度。

海陆主题提供“加入海陆差异”独立按钮，调用 `setLessonSurface` 同步模型状态、下拉选择与播放控制；加入时直接开始真实海陆演示，返回理想模型时清除路径并暂停。理想模型下直接播放或重播也会切换到真实海陆，静态理想对照不显示空播放进度。切换保留季节与区域选择。

探究打开时保存并暂停三维播放，背景控件设为 `inert`，Tab焦点留在窗口，Escape关闭并恢复焦点与原播放状态。固定播放区及主题导航支持小屏滚动；投屏模式放大文字、淡化干扰并扩大课堂图示。14道选择题保留答案及错误原因，可回看对应演示；迁移题提供评议依据而不自动评分。答案保留范围为同一页面会话，刷新不持久化。

窄屏三维讲解面板放在底部控制栏上方，过程播放区独立于滚动正文。手机尺寸或短窗口打开课堂后隐藏底部三维控制的展示，课堂面板接近全屏，主题可横向滚动，播放区与主题导航不缩小。隐藏欢迎页、教师栏、视频及关闭练习用可见性规则退出键盘焦点顺序。初始化失败由 `init().catch` 显示错误与重新加载按钮，避免无限停在进度条；此时尚不提供二维课堂独立降级运行。

`R` 恢复三维默认速度、弯曲、地表转动、粒子密度、图层、视角及未锁定状态，并退出省电与投屏，练习作答由各自的重置按钮清除。`tools/package.mjs` 按显式文件清单生成仅含成品和说明材料的交付目录；浏览器profile及文档加工中间文件被忽略，不进入交付。

### 3.3 场景取景与显示参数
`getSceneFraming` 根据可用视口计算取景距离，`frameScene` 使用偏移视锥为面板留空间。相机、观察目标及标签遮挡计算均以地球实际世界中心为参照，预设俯视、侧视、平视与重置不会沿用旧原点。

太阳圆盘始终朝向相机并写入深度，透明边缘通过 `alphaTest` 剔除，使后方箭头连接线被圆盘遮挡。箭头先计算大气层外侧安全轮廓目标，再以透视校正的插值缩短28个屏幕像素（短箭头最多缩短15%），在改变视角和窗口尺寸后保留间距。初始化在标签和气压带创建后调用 `setStepVisual` 与 `updateStepPanel`，确保无网址预设的首次打开也完整显示第一步提示和播放区。

“示意弯曲”调整机制路径与箭头；“地表转动”仅控制贴图旋转，第一步停止。两者均为显示参数，没有动力耦合。管道着色和粒子用于表示方向，不能视作真实气团沿闭合轨道的运动。

### 3.4 图示回归与验收
`diagramLatitudeY` 统一二维纬线、落点和环流位置。13个落点使用10种可复用标签，支持拖拽、点击与键盘；`diagramAnswers` 保留面板往返后的答案，判分统计全部13处，保留答案文字及对错标记。二维展开剖面中左为地面、右为高空，垂直运动表达为离地或趋地。

运行 `node tools/build.mjs` 后，用 `node tools/check-script.mjs 三圈环流3D交互式教学平台.html` 检查成品语法；启动本地服务后，用 `node tools/verify-acceptance.mjs http://127.0.0.1:8123/ artifacts/acceptance` 检查手动环节、箭头方向、视角、完整判分、订正、重置和离线成品入口。`verify-cross-section.mjs` 使用真实地球中心检查剖面位置与遮挡。

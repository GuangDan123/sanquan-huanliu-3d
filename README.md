# 三圈环流 3D 交互式教学平台

> 面向高中地理"气压带和风带"的三维交互认知工具
> 用可旋转、可分步、可调参的模型，呈现"单圈环流 → 地转偏向力介入 → 三圈环流成型 → 海陆分布与季风 → 季风环流与气候"的完整推导过程，
> 并通过**图示回归练习**完成从三维观察到二维图示的认知闭环。

---

## 快速开始

### 方式一：直接双击（推荐，无需任何环境）

双击 `三圈环流3D交互式教学平台.html` 即可在 Chrome / Edge / Firefox 中运行。

- **无需联网**：成品内嵌 Three.js 运行库与地球贴图，**不请求任何 CDN**；`libs/`与`assets/`用于源码构建；
- **无需服务器**：地球卫星纹理以 base64 内嵌，规避了 `file://` 协议的跨域限制；
- 若浏览器限制本地文件读取，改用方式二。

### 方式二：本地静态服务

```bash
node tools/serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

### 方式三：教师上课用的固定入口（跳过欢迎弹窗）

| URL 参数 | 效果 |
|---|---|
| `?state=guided` | 直接进入**第一步：理想单圈环流**（侧视、粒子与轨迹开启） |
| `?state=explore` | 直接进入**第二步：地转偏向力介入**（自定义模式、示意弯曲 12°） |
| `?state=diagram` | 直接进入**第三步 + 图示回归面板**（气压带风带全开） |
| `?state=landsea` | 直接进入**第四步：海陆分布与季风**（亚洲视角、1月气压中心） |
| `?state=monsoon` | 直接进入**第五步：季风环流与气候**（全球展开图、典型地区气温降水图） |

`file://` 下同样可用，例如：
`三圈环流3D交互式教学平台.html?state=diagram`

点击顶部“课堂路线”可按“单圈形成→三圈推导→季节移动→海陆与季风→降水与气候→独立作图→迁移解释”推进。路线中的节点聚焦可关闭，教师锁定视角后不会被自动调整；第四、第五步的月份、地区设置收在“月份、地区与播放设置”中。

第一步单圈已统一为第二步的渐变光带、细色芯、流动箭头和透明边缘大气层。南北半球各一条沿经线闭合的理想环流，赤道橙黄逐渐过渡到极地蓝色。点击播放后连续完成四个阶段，中间不自动暂停；完成后进度停留在10秒，箭头、粒子和波纹继续循环，地表缓慢转动。可手动暂停全部运动，继续流动时保留完成的环流；“从头重播”重新演示形成过程。进度条可回看，位置标记及“暂停并解释”可查看对应原因，拖动可改变观察角度。形成过程仍忽略自转对气流的偏转。详细记录见 [第一步单圈风格统一](docs/第一步单圈风格统一-20261013.md)。

第一步的动画按“阳光抵达大气层 → 赤道附近大气逐渐受热并转为橙黄色 → 地表空气受热上升”的因果顺序展开：前0.75秒只显示太阳辐射，随后大气层热区和赤道发光环渐显，1.45秒后才显示气团、向上光柱箭头、赤道低压与向内收缩的地表环波；受热上升段放慢到1.45—3.4秒，并在路径旁标注“受热上升”。上升时镜头平滑推近，随后回到全景；两极高压及向外扩散的环波随下沉渐显。暂停、回看和重播同步控制这些效果。太阳两条红色射线的间距缩小，拖动可接管特写视角，复位保留当前进度。

## 课堂用法（按课时选择路线）

点击左上角 **课堂探究**，按七个主题展开：风的成因 → 六个风带 → 季节移动 → 海陆与季风 → 标准剖面 → 理解练习 → 气候应用。每个演示先预测，解释可展开，播放、暂停、继续、重播位于固定操作区；关闭后返回三维。三维第一步及机制环节也提供对应入口。

- **风的成因**：直接点击“下一步”即可开始，按“气压梯度力推动 → 地转偏向力偏转 → 近地面摩擦影响”分三步播放，每步完成自动暂停，再点击“下一步”继续。中途暂停时，“下一步”继续当前步骤。可暂停/继续本步、回到上一步、重播本步或从头重播；从头重播也会逐步停下。
- **季节移动**：直接点击“播放季节循环”，约16秒演示春 → 夏 → 秋 → 冬 → 春，可暂停、继续和从头重播；单选春秋分、6月和12月可观察季节对照。直射点与气压带位置分别表达，各带移动幅度不同；幅度、带宽为教学示意。
- **海陆与季风**：点击“加入海陆差异”直接切换并播放；“返回理想模型”可来回对照。东亚、南亚冬夏四情境在播放前显示H高压、L低压区域，气流由高压源区指向低压目标区；冬季海洋较低压明确为相对大陆的气压比较。南亚夏季另显示东南信风跨赤道后右偏形成西南气流。理想模型下直接播放或重播也会加入海陆差异；解释区分季节尺度季风与昼夜尺度海陆风。
- **标准剖面**：横向纬度、纵向高度，可看两半球或单个半球，点击0°、30°、60°、90°对应垂直运动与近地面气压，返回三维定位。
- **理解练习**：17道风向、成因、季节与应用题，按基础、解释、迁移筛选；统计正确、错误、未完成，提供解释与相关演示入口。增加陌生气压场作图、可打印任务单及本地作答导出；自由作图与开放题由师生核对，不自动评分。
- **讲课停顿**：第一步单圈默认每个节点停住。第二步的四个形成环节使用同一条40秒时间轴连续播放，可随时暂停并弹出当前解释、继续、拖动进度、定位环节或从头重播。
- **标准剖面作图**：完整图、隐藏名称、隐藏箭头、空白图四种状态，支持箭头、画笔、自填文字、撤销和下载图示。
- **教材对照**：海陆页提供1月/7月气压分布与理想气压带叠加参考；季节及气候页可切换35°N/35°S固定地点，结合气温降水示意资料判断月份和降水条件。
- **第四步：海陆分布与季风**：点击底部“4”或第三步的“加入海陆分布”。在地球上连续观察海陆冷热变化、空气柱升降与高空输送、气柱粒子增减、气压中心展开、连续气压带在大陆中断，以及同一起点的气流逐渐右偏形成东亚季风。仅在相应节点出现简短标签，主画面不再显示右侧解释板。左侧可选月份、回看阶段、暂停、重播及结果对照；冬夏切换保留当前阶段并暂停，设置中可选择逐段讲解。可拖动缩放观察，气流、高度及时间均为教学示意。详细更新见 [第四步修改记录](docs/第四步修改记录-20261021.md)。
- **第五步：季风环流与气候**：点击底部“5”或第四步的“第五步”按钮，进入全球展开地图。可切换1月/7月，比较高低压中心、季风与平均风带；点击地图地点或选择北京、上海、孟买、达尔文，同步更新气温降水图和“环流→水汽→气候”的解释。图表默认读取JMA/TCC ClimatView的1991—2020年月常值，可切换教学示意，标注站号与来源，数据随成品内嵌。点击“先读真实资料，暂不显示结论”可先依据资料解释。气压及风线仍为教学示意；气候图表是独立资料，不是动画计算结果。小窗口可横向滚动地图、上下滚动内容。
- **教学路线**：第1课时侧重形成、风向与剖面；第2课时侧重季节、海陆及迁移，可另安排气候应用。投屏保留核心预测问题。
- **投屏模式**：放大三维文字，淡化太阳辐射光线并隐藏辅助图例；课堂探究中扩大图示、简化非练习页面。退出后恢复普通显示。
- **单圈太阳辐射**：保留两条红色箭头，平行指向地球模型；箭杆以等长虚线从太阳向地球缓慢流动（默认12像素/秒），每段约14像素、间隔约10像素，缩放和切换视角后仍保持平行与等长；箭杆宽度为太阳端2像素、地球端12像素，地球端保留18×24像素固定等腰三角尖端。教师暂停和速度调节同步作用于虚线。该动画表示太阳辐射能的传递方向，不表示实际光速。

教材对应：旧版人教必修1第二章第二节；新版人教选择性必修1第三章第二节。气候应用在新版可用于衔接下一节，请按学校使用的教材组织课时。教学优化与使用建议见 `docs/课堂教学优化.md`。

2026年10月10日形成机制更新：第四、第五步默认进入“形成机制”并等待教师开始。第四步包含季节衔接、海陆温差、气柱调整、气压中心、气压带改变、推动与季风六个节点，地球与右侧热力剖面同步。第五步展示源区、水汽、抬升冷却凝结与降水年变化；孟买夏季可增加气压带北移、东南信风与跨赤道右偏三个节点。提供上一节点、下一节点、重播本节点、从头重播、连续复习和结果对照；解释只揭示当前节点，气候图与全年结论随进度出现。第四步返回时恢复原区域与进度并暂停。小屏图示支持滚动，可折叠第四步剖面观察地球。实施与验收见 [形成机制实施与验证](docs/形成机制实施与验证-20261010.md)。

### 演示模式（评委/公开课一键演示）

点击右上角**教师端 → 演示模式**，进入侧视下的第二步机制演示。
点击第二步“播放过程”，连续观察四个环节：高空右偏 → 30°下沉分流 → 60°交汇抬升 → 三圈归纳。形成环节自动衔接，最终停留第二步；点击“第三步”再进入稳定环流。

发光气流在同一个地球模型上逐段展开：赤道上升后向北输送，逐渐右偏为向东运动，接近北纬30°时与纬线平行，随后积聚、下沉，形成副热带高气压带并近地面分流。赤道、30°纬线和无偏转经线提供对照，青色箭头表示水平偏向方向。第二步使用固定的教材过程，隐藏示意弯曲参数；此为机制示意，不是动力数值模拟。

点击“暂停并解释”会冻结全部气流，弹出与当前进度对应的解释；可选择“保持暂停”或“继续播放”。教师端暂停也会弹出解释。拖动进度条可回看任意位置，点击1–4可定位对应形成环节；“从头重播”重播整个连续过程。解释明确区分水平偏转与下沉，地转偏向力不是直接向下的力。

第二步先形成低纬环流，再并行形成中纬、高纬环流。23秒起两侧近地面气流同时向60°附近输送；27—30秒各自上升；30—33秒中纬与高纬高空回流同时展开，两圈在33秒同步闭合。每个半球的三圈各自拥有完整独立的路线，在纬度方向小幅错开，相邻支路间隔4°；30°下沉支与60°上升支分别绘制，连接本圈的回流。已形成环流持续保留。默认镜头沿气流推进，在赤道上升、30°下沉、60°抬升和极地下沉时平滑推进做特写；38—40秒平滑拉回全景，完整呈现南北半球三圈。黄色气团标出当前位置，独立圈之间平滑转场时暂时隐藏。可随时切换“全景观察”或“跟随气流”。暂停同步冻结镜头、气流和气压带，继续与重播保持同一进度。

南北半球共22个位置说明对应升降支、积聚、高空回流和风向形成。当前环节显示简短解释，其余位置保留标题；点击对应标记或文字可暂停并查看详细解释。形成过程中，近地面粒子的增加或减少示意空气质量变化：下沉与空气质量补充形成高压，上升与高空质量输出形成低压。气压带随垂直运动整带渐显：赤道黄色`#ffd447`、30°附近绿色`#72d44a`、60°附近蓝色`#329bff`、两极紫色`#b986ff`，第二步与成型模型保持一致。底部“气压带”“标注”开关控制显示。最新自验收见 [气压形成特写与位置解释验收](docs/气压形成特写与位置解释验收-20261013.md)。
60°附近的冷暖气流在27秒交汇后，暖色中纬气流在27—30秒沿倾斜极锋持续向高纬侧、向高空爬升；30秒到达高空接点后，中纬与高纬回流同时展开。副极地低气压带与爬升同步形成。跟随镜头在此阶段平滑转向侧面，呈现斜坡路径。冷气团在交汇前逐渐出现，高纬演示开始后淡出；爬升路线与已形成的中纬气流继续保留。暂停与回看同时控制冷气团、爬升气流和气压带。极锋坡度与高空接点纬度为教学示意。

播放中、暂停时和演示结束后，均可直接拖动三维画面观察不同角度，也可滚轮缩放或触屏拖动。操作从当前视角接管镜头，气流继续按原进度播放，环流模型保持空间方向。点击“跟随气流”可重新开启自动跟随。

环流路径的所有折角均改为平滑圆弧，覆盖赤道回转、30°升降连接、中纬极锋顶部和极地回转；光带、粒子和箭头共用圆弧路径。圆弧在原路线接点附近小幅内收，保持三圈独立、地表以上和大气层以内。气压带参照第三步改为清晰的实色宽带：一般宽5°、极地宽8°，形成后的透明度0.92；名称使用深色底、对应颜色边框和↑上升/↓下沉标记。气压带仍随升降过程整带逐渐形成。

30°附近低纬与中纬两条下沉支在15—19秒同步展开，此后持续显示；中纬其余路线随后形成。位置说明默认只展开当前环节，其余位置收成小标记；悬停或聚焦显示标题，点击暂停并查看详细解释。文字排布避开当前可见气流及其他标签，气压带名称移至路线外侧，必要时用细引线对应位置。结束全景自动收起过程说明文字，保留气压带名称及可点击的位置标记。

第二步统一采用分区冷暖配色：低纬暖气流橙黄`#ffb52e`、冷气流黄绿`#b6dc45`；中纬暖气流黄绿、冷气流蓝绿`#16c8b5`；高纬全部蓝色`#2586ff`。低纬高空从赤道橙黄渐变至30°黄绿，近地面从30°黄绿渐变至赤道橙黄。中纬近地面从30°黄绿渐变至60°蓝绿，高空从极锋爬升接点蓝绿渐变至30°黄绿。低纬与中纬独立下沉段均为黄绿，中纬独立爬升段为蓝绿，高纬独立上升段为蓝色，各圈连接处颜色连续；整条光带、色芯与粒子使用同一配色。面板分别提供三圈渐变色标和四类气压带色标。高空路径高度由0.66提高到1.45，上升和下沉的垂直跨度由0.58提高到1.37；透明大气层半径7.05，位于所有气流光带外侧，包裹地球与三圈。颜色、高度及纬度错开均为教学示意，自由观察保持可用。

三圈增加沿气流方向移动的箭头：每个半球低纬4个、中纬3个、高纬2个，形成过程中只显示已形成路线上的箭头。位置始终按完整闭合路线的固定弧长计算，路线增长不会重新分配箭头或造成倒退；箭头与所在位置的冷暖渐变颜色一致。形成过程结束后，进度固定在40秒，箭头、粒子和光带继续流动，地球继续自转。点击“暂停并解释”同步冻结运动，点击“继续播放”或“继续流动”恢复运动；“从头重播”重新演示形成过程，“轨迹”开关同时控制箭头。

30°高空积聚位置增加柔和的黄绿色气团：12—15秒粒子逐渐增多、聚拢；15—19秒从气团向副热带高压带同步延伸两条半透明光柱，位于两条下沉支之间，柱内箭头持续向下移动。形成后气团略微淡化，光柱与箭头保留；暂停、继续、回看和结束后的流动共用原有时间控制。“粒子”控制气团，“轨迹”控制光柱及柱内箭头；文字避让同时考虑新增效果。跟随期间改变窗口尺寸后，切回全景会按当前尺寸重新适配。

第二步标签随当前镜头显示：对应位置超出可用画面时，标签与引线暂时隐藏，重新进入画面后自动恢复。气压带名称若无法在附近完整排下，或需要超过160像素的引线，也暂时隐藏；特写不会把远处名称强行挤入画面边缘。

位置标签直接说明气流方向与形成原因：“地转偏向力：北半球向右偏”，南半球对应向左偏；信风为“30°→赤道”，盛行西风为“30°→60°”，极地东风为“两极→60°”。升降说明采用“地面空气增多/减少”，详细解释保留气柱质量收支、极锋与动力性/热力性气压等术语。左右以气流前进方向为准。赤道附近两条上升支共用同一经度，分别在2°N、2°S，连接各自的高空输送与地面回流，圆弧与闭合保留；4°间隔为便于观察的示意。

点击“暂停并解释”后仍可拖动地球、滚轮缩放或触屏观察，解释窗口保持打开，气流和地球自转保持静止。手机解释窗口放在下方操作区，上方三维画面留给拖动；点击“继续播放”从暂停进度继续。

30°高空气团宽度与粒子分布扩大约50%，保持柔和、半透明。赤道两条上升支之间增加橙黄色气团与两条上升光柱，柱内箭头沿上升方向移动，气团、光柱、箭头均与赤道上升线条配色一致。赤道气团位于上升路径顶部、高空回流连接处，高度1.53，在上一版基础上再扩大50%；1.5—4秒随上升气流抵达高空逐渐显现，随后保留。暂停、回看、结束后的流动以及图层开关同步控制两处效果。

30°下沉光柱的地面落点增加绿色环形波纹，由内向外扩散，标注“高压”；赤道上升支底部增加黄色环形波纹，由外向内收缩，标注“低压”。波纹随对应升降过程显现，与箭头同步暂停和继续，形成结束后仍流动；“气压带”开关控制波纹，“标注”开关控制文字。地球下方的字幕条已去除，当前过程说明仍在步骤面板与气流位置显示。

副热带高气压带名称直接放在绿色带上，不使用连接线，并沿色带寻找不遮挡气流的位置；装不下时暂时隐藏。“高压”使用红色胶囊框，“低压”使用浅蓝色胶囊框，与气压带名称区分。底部视角区的“复位地球”恢复初始全景视角与缩放，拖动、缩放或暂停解释后均可使用，当前播放进度和暂停状态保留；重新点击“跟随气流”可继续自动镜头。

第二步补上南北纬30°浅色虚线，位于气压带表面外侧，形成后仍清晰可见；“网格”开关控制这两条参考纬线，暂停时切换也生效。“从头重播”自动恢复气流跟随，拖动、复位或切换全景后重播均从赤道重新推进镜头。

低纬气流按行进路线连续展开：高空输送完成后，12—15秒再形成30°附近的水平段，随后进入下沉；宽光带与细线共用绘制进度，避免提前出现孤立线段。

跟随镜头的推近、拉远与转向经过平滑处理，升降特写使用更缓的过渡；播放开始时视野渐变，镜头路线在播放前准备，减少开头的突然变化。暂停冻结位置、转向与缩放，回看仍可复现相同视角。

按 `H` 可隐藏全部 UI，只留纯净三维画面，便于录屏。

> **关于引导弹窗**：仅在**第一步**弹出文字说明弹窗（气流暂停，等待学生阅读，点"继续"恢复）。
> 第二步的解释弹窗由“暂停并解释”或教师端暂停触发，可保持暂停或继续播放。第三步通过知识卡片解释结果。

## 构建与交付

维护源码后先运行 `node tools/build.mjs`，再运行 `node tools/package.mjs`。后者在 `release/` 创建独立交付目录，只复制成品和说明材料，不包含浏览器缓存、开发工具及文档加工中间文件。交付目录可直接复制给教师。交付目录按“气压带与风带-日期-提交号”命名，脚本自动保留最新 3 份，避免历史构建无限累积。

浏览器验收脚本使用 Node.js 和本机 Chrome。新检出项目后，运行 `npm ci --prefix artifacts/sequence-runtime` 安装验收依赖，再运行相应的 `tools/verify-*.mjs`。当前脚本默认使用 Windows 的 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他系统需调整浏览器路径；教学成品本身无需安装这些依赖。验收脚本的 Chrome 配置目录统一放在系统临时目录并在退出时清理，不再写入项目。

验收截图默认每个功能目录保留 6 张关键图，文档直接引用的图片始终保留。可先运行 `node tools/prune-artifacts.mjs` 预览，再运行 `node tools/prune-artifacts.mjs --apply --keep=6` 清理；该工具同时删除误留的浏览器缓存、未完成下载和过量截图。最新镜头、特写与复位检查见 `artifacts/smooth-camera-20261013/`。

`artifacts/` 作为本地验收区默认不进入 Git；需要长期入库的精选报告可用 `git add -f` 加入。

## 功能清单

**三维呈现**
- 五层地球模型：地表 + 云层 + 大气辉光 + 外发光 + 边缘散射光晕（自定义 shader）
- 环流管道 + 管内流动条纹（shader 驱动的方向感）+ 粒子流（每半球最大哈德莱 240 / 费雷尔 200 / 极地 200；默认中等密度绘制75%）
- 三段色彩编码：低纬暖橙（哈德莱）、中纬黄（费雷尔）、高纬蓝（极地）
- 3000 星点星空背景、经纬网格、纬线标注

**分步推导（核心叙事）**
1. **理想单圈环流** —— 假设地球不自转，赤道上升、极地下沉，形成单一闭合热力环流（高空橙 / 近地面蓝双色区分）
2. **地转偏向力介入** —— 四个形成环节连续衔接；同一地球上的发光气流逐段呈现偏转、30°积聚下沉、60°辐合上升和三圈归纳，可随时暂停解释
3. **三圈环流成型** —— 归纳哈德莱、费雷尔、极地三圈，叠加七个气压带与六个风带箭头

**交互控制**
- 视角：俯视 / 侧视 / 平视 / 重置；鼠标拖拽旋转、滚轮缩放
- 图层：网格、粒子、轨迹、气压带、标注、图例（6 个独立开关）
- 参数：播放速度（0.1–2.0×）、示意弯曲幅度（0–45°）、地表转动显示、粒子密度；示意弯曲不驱动动力数值模型
- 知识卡片：点击图例、气压带或风带标签弹出对应知识点
- 教师端：播放暂停、步骤跳转、锁定视角、手动机制演示
- 性能：省电模式（降像素比 + 按当前密度将绘制与每帧更新的粒子降至40% + 关闭流动条纹）；暂停时切换也立即生效
- 无障碍细节：隐藏面板退出键盘焦点顺序，课堂窗口支持Tab与Escape；紧凑按钮36–38px，常规按钮44px；CSS2D 标签做背面剔除，地球背面的标注自动隐藏

**图示回归练习（教学闭环）**
- Canvas 2D 绘制三圈环流剖面图 + 纬度参考线
- 13 个拖拽落点（赤道低压 / 副热带高压 ×2 / 副极地低压 ×2 / 极地高压 ×2 + 六风带）
- 10 个可重复使用的标签随机排序，支持拖拽或点击放置；"检查答案"分别统计正确、错误与未完成（✓ / ✗）
- 三维联动：在 3D 中点开知识点时，二维图对应区域闪烁高亮

## 常见问题

**Q：打开是黑屏，一直停在"正在加载教学资源"？**
A：请确认打开的是根目录成品HTML，而不是含构建占位符的 `src/index.src.html`。成品已内嵌运行库；初始化失败会显示错误提示和“重新加载”按钮。检查浏览器WebGL支持及图形加速设置后重试。

**Q：地球是手绘色块而不是卫星图？**
A：成品已内嵌卫星纹理，纹理解析失败时会使用回退图像或程序化纹理。维护源码时请确认纹理文件完整并重新构建成品。

**Q：欢迎页没有"课堂实录"按钮？**
A：这是**预期行为**。`assets/video/classroom.mp4` 尚未录制，入口按钮处于注释状态。录制完成后，取消 HTML 中该按钮一行的注释即可恢复（代码已内置"视频不存在则自动隐藏按钮"的保护逻辑）。

**Q：能在平板 / 手机上用吗？**
A：支持点击选择标签后点击落点，键盘也可操作；手机竖屏的机制面板位于底部，课堂窗口充分利用屏幕，主题导航和图示可横向滑动，图示保留文字尺寸，播放区和上一/下一主题固定可见。已用360×640、390×844和844×390浏览器窗口验证布局；真实设备触摸与iOS尚需在上课前试用。

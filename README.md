# 三圈环流 3D 交互式教学平台

> 面向高中地理"气压带和风带"的三维交互认知工具
> 用可旋转、可分步、可调参的三维模型，呈现"单圈环流 → 地转偏向力介入 → 三圈环流成型"的完整推导过程，
> 并通过**图示回归练习**完成从三维观察到二维图示的认知闭环。

---

## 快速开始

### 方式一：直接双击（推荐，无需任何环境）

双击 `三圈环流3D交互式教学平台.html` 即可在 Chrome / Edge / Firefox 中运行。

- **无需联网**：Three.js 运行库（`libs/`）与地球贴图（`assets/`）均随作品包分发，**不请求任何 CDN**；
- **无需服务器**：地球卫星纹理以 base64 内嵌，规避了 `file://` 协议的跨域限制；
- 若浏览器限制本地文件读取，改用方式二。

### 方式二：本地静态服务

```bash
node tools/serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

### 方式三：教师上课用的固定入口（跳过欢迎弹窗）

| URL 参数 | 效果 |
|---|---|
| `?state=guided` | 直接进入**第一步：理想单圈环流**（侧视、粒子与轨迹开启） |
| `?state=explore` | 直接进入**第二步：地转偏向力介入**（自定义模式、偏转角 20°） |
| `?state=diagram` | 直接进入**第三步 + 图示回归面板**（气压带风带全开） |

`file://` 下同样可用，例如：
`三圈环流3D交互式教学平台.html?state=diagram`

## 课堂用法（一课时）

| 环节 | 操作 | 学生任务 |
|---|---|---|
| 导入（约 3 min） | 打开第一步，提问"若地球不自转，大气如何运动？" | 预测气流方向 |
| 机制建构（约 8 min） | 切到第二步，观察 30°、60° 出现的弯折节点与黄色偏转箭头长度变化 | 说明"单圈为什么会分裂" |
| 三圈成型（约 7 min） | 切到第三步，开启**气压带**图层 | 对照说出七个气压带、六个风带 |
| 图示回归（约 7 min） | 打开右侧"图示回归"面板，拖拽标签补全剖面图 | 把三维所见画成二维图 |
| 自主探究（约 5 min） | 切"自定义模式"，拖动**偏转角**"自转速度"滑块 | 推演极端情境下的环流变化 |

### 演示模式（评委/公开课一键演示）

点击右上角**教师端 → 演示模式**，或按快捷键，系统自动执行：
侧视 → 第一步 → 第二步 → 第三步 + 图示回归（约 15 秒自动串场）。
按 `H` 可隐藏全部 UI，只留纯净三维画面，便于录屏。

> **关于引导弹窗**：仅在**第一步**弹出文字说明弹窗（气流暂停，等待学生阅读，点"继续"恢复）。
> 第二步、第三步**不再弹出模态框**，直接进入动态演示——左侧常驻知识点面板会同步显示对应原理，
> 不遮挡三维画面，便于讲解与录屏。

### 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 切换到引导 / 自定义探索 / 图示回归预设 |
| `H` | 隐藏 / 恢复全部 UI（录屏用） |
| `R` | 重置到初始状态 |

## 功能清单

**三维呈现**
- 五层地球模型：地表 + 云层 + 大气辉光 + 外发光 + 边缘散射光晕（自定义 shader）
- 环流管道 + 管内流动条纹（shader 驱动的方向感）+ 粒子流（哈德莱 240 / 费雷尔 200 / 极地 200，南北半球各一组）
- 三段色彩编码：低纬暖橙（哈德莱）、中纬黄（费雷尔）、高纬蓝（极地）
- 3000 星点星空背景、经纬网格、纬线标注

**分步推导（核心叙事）**
1. **理想单圈环流** —— 假设地球不自转，赤道上升、极地下沉，形成单一闭合热力环流（高空橙 / 近地面蓝双色区分）
2. **地转偏向力介入** —— 30°、60° 浮现弯折节点与偏转力箭头，箭头长度随纬度增强，环流带开始出现分段渐色
3. **三圈环流成型** —— 分裂为哈德莱、费雷尔、极地三圈，叠加七个气压带与六个风带箭头

**交互控制**
- 视角：俯视 / 侧视 / 平视 / 重置；鼠标拖拽旋转、滚轮缩放
- 图层：网格、粒子、轨迹、气压带、标注、图例（6 个独立开关）
- 参数：播放速度（0.1–2.0×）、偏转角（0–45°）、自转速度、粒子密度
- 知识卡片：点击环流圈 / 图例 / 气压带标签弹出对应知识点
- 教师端：播放暂停、步骤跳转、锁定视角、演示模式自动串场
- 性能：省电模式（降像素比 + 粒子降至 40% + 关闭流动条纹 shader）
- 无障碍细节：UI 全部按钮最小高度 44px（触控友好）；CSS2D 标签做背面剔除，地球背面的标注自动隐藏

**图示回归练习（教学闭环）**
- Canvas 2D 绘制三圈环流剖面图 + 纬度参考线
- 13 个拖拽落点（赤道低压 / 副热带高压 ×2 / 副极地低压 ×2 / 极地高压 ×2 + 六风带）
- 10 个可拖拽标签随机排序，"检查答案"即时判分（✓ / ✗）
- 三维联动：在 3D 中点开知识点时，二维图对应区域闪烁高亮

## 常见问题

**Q：打开是黑屏，一直停在"正在加载教学资源"？**
A：说明 `libs/three/three.module.js` 缺失或被移动。请确认 `libs/` 目录与 HTML 文件在同一层级（作品中已本地化，正常情况下不会出现此问题）。

**Q：地球是手绘色块而不是卫星图？**
A：说明 `assets/textures/earth_tex.js` 未加载成功，程序已自动回退到 Canvas 程序化纹理。请检查 `assets/` 是否随包分发。

**Q：欢迎页没有"课堂实录"按钮？**
A：这是**预期行为**。`assets/video/classroom.mp4` 尚未录制，入口按钮处于注释状态。录制完成后，取消 HTML 中该按钮一行的注释即可恢复（代码已内置"视频不存在则自动隐藏按钮"的保护逻辑）。

**Q：能在平板 / 手机上用吗？**
A：可以。已做响应式适配（768px 以下隐藏左侧知识点面板，图示回归面板改为底部抽屉）。建议横屏使用。

# 三圈环流 3D 交互式教学平台

> 面向高中地理"气压带和风带"的三维交互认知工具
> 用可旋转、可分步、可调参的三维模型，呈现"单圈环流 → 地转偏向力介入 → 三圈环流成型"的完整推导过程，
> 并通过**图示回归练习**完成从三维观察到二维图示的认知闭环。

---

## 快速开始

### 方式一：直接双击（推荐，无需任何环境）

双击 `三圈环流3D交互式教学平台.html` 即可在 Chrome / Edge / Firefox 中运行。

- **无需联网**：成品内嵌 Three.js 运行库与地球贴图，**不请求任何 CDN**；`libs/`与`assets/`用于源码构建；
- **无需服务器**：地球卫星纹理以 base64 内嵌，规避了 `file://` 协议的跨域限制；
- 若浏览器限制本地文件读取，改用方式二。

### 方式二：本地静态服务

```bash
node tools/serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

### 方式三：教师上课用的固定入口（跳过欢迎弹窗）

| URL 参数 | 效果 |
|---|---|
| `?state=guided` | 直接进入**第一步：理想单圈环流**（侧视、粒子与轨迹开启） |
| `?state=explore` | 直接进入**第二步：地转偏向力介入**（自定义模式、示意弯曲 12°） |
| `?state=diagram` | 直接进入**第三步 + 图示回归面板**（气压带风带全开） |

`file://` 下同样可用，例如：
`三圈环流3D交互式教学平台.html?state=diagram`

## 课堂用法（一课时）

点击左上角 **课堂探究**，按七个主题展开：风的成因 → 六个风带 → 季节移动 → 海陆与季风 → 标准剖面 → 理解练习 → 气候应用。每个演示先预测，解释可展开，播放、暂停、继续、重播位于固定操作区；关闭后返回三维。三维第一步及机制环节也提供对应入口。

- **季节移动**：直接点击“播放季节循环”，约16秒演示春 → 夏 → 秋 → 冬 → 春，可暂停、继续和从头重播；单选春秋分、6月和12月可观察季节对照。直射点与气压带位置分别表达，各带移动幅度不同；幅度、带宽为教学示意。
- **海陆与季风**：点击“加入海陆差异”直接切换并播放；“返回理想模型”可来回对照。也可选择冬夏及东亚/南亚；南亚夏季另外显示东南信风跨赤道后右偏形成西南气流。理想模型下直接播放或重播也会加入海陆差异。
- **标准剖面**：横向纬度、纵向高度，可看两半球或单个半球，点击0°、30°、60°、90°对应垂直运动与近地面气压，返回三维定位。
- **理解练习**：14道风向、成因、季节与应用题，分开统计正确、错误、未完成，提供解释与相关演示入口；开放迁移题保留作答，并提供4点评议依据，由师生讨论评分。关闭重开保留作答，重置清除。
- **投屏模式**：放大三维文字，淡化太阳辐射光线并隐藏辅助图例；课堂探究中扩大图示、简化非练习页面。退出后恢复普通显示。

教材对应：旧版人教必修1第二章第二节；新版人教选择性必修1第三章第二节。气候应用在新版可用于衔接下一节，请按学校使用的教材组织课时。教学优化与使用建议见 `docs/课堂教学优化.md`。

| 环节 | 操作 | 学生任务 |
|---|---|---|
| 导入（约 3 min） | 打开第一步，提问"若地球不自转，大气如何运动？" | 预测气流方向 |
| 机制建构（约 8 min） | 切到第二步，逐环节预测、显示解释并观察箭头 | 解释30°下沉分流、60°交汇抬升，归纳三圈 |
| 三圈成型（约 7 min） | 切到第三步，开启**气压带**图层 | 对照说出七个气压带、六个风带 |
| 图示回归（约 7 min） | 打开右侧"图示回归"面板，拖拽标签补全剖面图 | 把三维所见画成二维图 |
| 自主探究（约 5 min） | 切"自定义模式"，调整**示意弯曲**与地表转动显示 | 比较机制示意；明确参数不代表动力数值模拟 |

### 演示模式（评委/公开课一键演示）

点击右上角**教师端 → 演示模式**，进入侧视下的第二步机制演示。
用左侧“显示解释”“上一环节”“下一环节”推进四个环节：高空偏转 → 30°下沉分流 → 60°交汇抬升 → 三圈归纳；最后进入第三步。不会自动串场。

首环节点击“播放过程”，橙色高空气团从低纬向极地移动，对照灰色经线参考逐渐向东偏转；青色箭头始终指向当前水平运动的侧方。右下角同步俯视对照图保持上北下南、右东，便于判断向北右偏、向南左偏，两者均获得东向分量。1倍速约10秒，支持暂停、继续、重播；设示意弯曲为0可观察沿经线运动。此为方向与过程示意，不是动力数值模拟。

在“30°积聚下沉与近地面分流”中，先预测，再点击“播放过程”：高空气流汇入 → 逐渐积聚 → 下沉并形成近地面高压 → 向赤道与较高纬度分流 → 归纳哈德莱环流。1倍速约12秒，可“暂停过程”“继续过程”“从头重播”；教师端暂停也会冻结过程。完成后仍停留本环节，教师自行决定何时进入60°环节。

在“60°冷暖气流交汇与上升”中，约10秒呈现辐合 → 较暖空气沿较冷空气上方抬升 → 副极地低压与高纬环流归纳。局部剖面同步显示，支持暂停与重播；完整高纬圈只在最后归纳时出现，中纬圈仍留到第四环节。
按 `H` 可隐藏全部 UI，只留纯净三维画面，便于录屏。

> **关于引导弹窗**：仅在**第一步**弹出文字说明弹窗（气流暂停，等待学生阅读，点"继续"恢复）。
> 第二步、第三步**不再弹出模态框**，直接进入动态演示——左侧常驻知识点面板会同步显示对应原理，
> 不遮挡三维画面，便于讲解与录屏。

## 功能清单

**三维呈现**
- 五层地球模型：地表 + 云层 + 大气辉光 + 外发光 + 边缘散射光晕（自定义 shader）
- 环流管道 + 管内流动条纹（shader 驱动的方向感）+ 粒子流（哈德莱 240 / 费雷尔 200 / 极地 200，南北半球各一组）
- 三段色彩编码：低纬暖橙（哈德莱）、中纬黄（费雷尔）、高纬蓝（极地）
- 3000 星点星空背景、经纬网格、纬线标注

**分步推导（核心叙事）**
1. **理想单圈环流** —— 假设地球不自转，赤道上升、极地下沉，形成单一闭合热力环流（高空橙 / 近地面蓝双色区分）
2. **地转偏向力介入** —— 四个手动机制环节，先预测再显示解释；三圈分阶段出现，不按时间把单圈淡出为三圈
3. **三圈环流成型** —— 归纳哈德莱、费雷尔、极地三圈，叠加七个气压带与六个风带箭头

**交互控制**
- 视角：俯视 / 侧视 / 平视 / 重置；鼠标拖拽旋转、滚轮缩放
- 图层：网格、粒子、轨迹、气压带、标注、图例（6 个独立开关）
- 参数：播放速度（0.1–2.0×）、示意弯曲幅度（0–45°）、地表转动显示、粒子密度；示意弯曲不驱动动力数值模型
- 知识卡片：点击环流圈 / 图例 / 气压带标签弹出对应知识点
- 教师端：播放暂停、步骤跳转、锁定视角、手动机制演示
- 性能：省电模式（降像素比 + 粒子降至 40% + 关闭流动条纹 shader）
- 无障碍细节：UI 全部按钮最小高度 44px（触控友好）；CSS2D 标签做背面剔除，地球背面的标注自动隐藏

**图示回归练习（教学闭环）**
- Canvas 2D 绘制三圈环流剖面图 + 纬度参考线
- 13 个拖拽落点（赤道低压 / 副热带高压 ×2 / 副极地低压 ×2 / 极地高压 ×2 + 六风带）
- 10 个可重复使用的标签随机排序，支持拖拽或点击放置；"检查答案"分别统计正确、错误与未完成（✓ / ✗）
- 三维联动：在 3D 中点开知识点时，二维图对应区域闪烁高亮

## 常见问题

**Q：打开是黑屏，一直停在"正在加载教学资源"？**
A：请确认打开的是根目录成品HTML，而不是含构建占位符的 `src/index.src.html`。成品已内嵌运行库；若仍无法加载，请检查浏览器WebGL支持并查看控制台报错。

**Q：地球是手绘色块而不是卫星图？**
A：成品已内嵌卫星纹理，纹理解析失败时会使用回退图像或程序化纹理。维护源码时请确认纹理文件完整并重新构建成品。

**Q：欢迎页没有"课堂实录"按钮？**
A：这是**预期行为**。`assets/video/classroom.mp4` 尚未录制，入口按钮处于注释状态。录制完成后，取消 HTML 中该按钮一行的注释即可恢复（代码已内置"视频不存在则自动隐藏按钮"的保护逻辑）。

**Q：能在平板 / 手机上用吗？**
A：支持点击选择标签后点击落点，键盘也可操作；小屏保留机制面板，图示回归改为底部抽屉，视角按可用空间调整。建议横屏使用；具体设备仍应在上课前试用。
